# 配音时间与阅读字幕验收

日期：2026-10-25。关联 FW-R03、FW-R05、FW-R07、FW-R08、FW-R11、FW-R12、FW-R15、FW-R17。完整目标继续推进；本轮实现时间证据到字幕的链路，不将夹具、编译或局部界面当作真实语音质量和全产品完成。

规格见 [配音时间与阅读字幕接口](../specs/2026-10-25-配音时间与阅读字幕接口.md)。

## 实现

语音任务显式选择 withTiming 后只提交带时间端点一次。两套字符对齐、缺失时间和畸形原始字段独立保留；合法音频不因坏时间被丢弃，也不偷偷改走普通配音或识别。时间摘要与操作、音色、模型及音频 SHA 共同持久化，本地恢复不再次 POST，旧普通配音兼容。

应用层进一步检查原文字符是否精确匹配输入、所选时间是否齐全有序并落在真实音频内；规范化朗读文本由用户明确选择。字符到词只使用实际边界，组合字形、英文空格和标点保留；没有可绑定时间时仍可导音频。长字符链使用有界线性构建，避免逐项复制整段字符串。

音频、时间源词及字幕一次上轨并整组 Undo。配音来源标为 tts，原文/朗读时间标明 timingSource，不伪装为 ASR；RawWords 和接受版本仍分开。已经上轨的同一素材不重复插入，字幕跟随全部引用片段；已有分割和人工修订不能因再次导入被覆盖。

阅读分句维护多词持续绑定，按真实首末时间和帧映射处理；逐词仍是旧工程默认。分句考虑标点、停顿、说话人、字数、行数和时间上限。人工文字、样式及布局形成保护组，无法确定部分修剪归属时原子拒绝。排版通过后端预览和 ID 应用，源指纹、工程实例、版本和锁轨继续生效；新建目标轨与重排同一事务。

MCP 提供受控预览/应用工具，接受词和结构上下文包含来源与排版元信息。普通编辑和结构计划不能夹带未经核对的排版参数。

## 已取得的证据

speech/speechjobs 的本地 HTTP 与持久任务回归验证：显式 timed 一次 POST、默认 plain、缺失/null/畸形对齐、原文与规范化不同、写失败仅本地恢复、重启不获取凭据或重新 POST、取消未知不重放、音频/音色/模型/时间摘要篡改，以及旧普通回执兼容。没有真实样本计数源时 SampleCount 严格为 null。

应用回归覆盖原文匹配、明确朗读来源、音频与字幕整组撤销、保存重开、缺失时间的音频独立导入、分割后补字幕不重复音频；排版覆盖预览无修改、手改保护、锁轨、陈旧版本/同 ID 重开、文件变化、受控 MCP 和明确新轨。

定向审查复现并修复：已上轨配音重定位到相同内容副本后，该副本又变化，但任务原文件完好；旧导入只核查任务原件，会为已变工程音频接纳字幕。现在同时核查工程实际播放路径，并在提交前确认路径、指纹、时长和存在状态未变。永久回归为 `TestTimedSpeechCaptionsVerifyRelinkedProjectAudioRatherThanReceiptCopy`，修后全部带时应用 race 通过。

`work/fixtures/timed-captions/main.go` 通过真实 ElevenLabs 协议适配器访问本地 HTTP 假服务，输入为自建 523.25Hz/2秒 MP3 和合成字符时间；准备两项任务共2次本地 POST，真实模型调用0。数据通过实际任务管理器落盘，未手写成功任务 JSON。各 Go 夹具放在独立命令目录，避免多个 main 混在同一包。

`work/check_timed_captions_api.py` 连接真实 Go HTTP、FFmpeg/ffprobe，证据 `work/timed-captions-check/api-evidence.json`：

- 原文“12号开始测试配音字幕。”与朗读文本“十二号开始测试配音字幕。”分开；缺原文时间不能借另一套，但音频仍可单独导入。
- 10条逐词字幕变成1条两行阅读字幕，仍引用真实有序多个词；预览不改工程，原始词未改写。
- 配音及字幕整组 Undo/Redo、人工覆盖保护、保存重开、SRT 导出通过。
- 逐词/阅读两版实际导出 PCM RMS 均为 `0.05931451565719511`。该夹具证明字幕重排没有丢失或重复音频贡献，不证明真实发音、语义分句或所有编码质量。
- 实际合成帧已查看：文字与换行位于640×360画面内。字体/浏览器与正式渲染的一致性仍属后续完整验收。

编辑核心新增阅读组语义与规模回归，覆盖中文标点、英文空格、组合字形、词间停顿/说话人、播放速度下的持续时间、手改组、修剪/分割/复制及旧讲话来源替换、排除、锁轨、非法多词引用和旧 schema。实际100000词唯一覆盖检查通过，派生12500条阅读字幕；不将该结果外推为整机流畅度。

实际 Playwright 界面连接真实 Go 服务，验证默认不请求配音时间、摘要不自动读大结果、缺原文时间时禁字幕且保留音频、明确配音来源、音频/10条逐词字幕一次上轨，以及任务按钮自动展开分句设置。稳定界面观察10→1预览不建轨，明确新轨应用后轨道4→5、片段11→2；一次 Undo 恢复4轨11片段，未重复音频。阅读文字在第40帧实际显示，截图 `output/playwright/timed-caption-preview.png` / `timed-caption-applied.png` 已查看，摘要 `work/timed-captions-ui-evidence.json`。

本轮还复现并修复三项边界：

- 同时新建目标轨和改阅读模式时，旧自动字幕一度被按新基准误记为手改；现用命令前基准判断保护，真正手改/旧布局仍保留，前后端回归覆盖。
- Undo 删除刚建轨后，界面曾显示新建却发送已删除的轨道 ID；现恢复有效目标并保留排版草稿、使旧预览失效。实际再次预览成功，新增2项 DOM 回归。
- 旧工程没有样式标志的手工布局实际受到核心保护，影响统计曾漏报；现按实际派生保护结果统计，永久应用回归通过。

最终18个内部 Go 包全量 race、Go vet 通过；最后保护统计修复后应用定向 race 再通过。前端129项测试、类型、格式、构建及静态设计审计通过，主包498.56KB/gzip155.05KB，新增大面板按需加载。稳定浏览器最终 console error/warning 均0。

macOS arm64 `.app` 构建与本地自签名验证、Windows GUI amd64 交叉编译通过，构建哈希见 `work/timed-captions-build-evidence.json`；商业签名、安装更新、双端原生运行与本轮新功能实机操作仍未验收。专用浏览器及43111/5174服务在验收结束后关闭，原有服务和原生草稿未接管。

## 限制与后续

尚未使用真实语音账户验证发音、数字规范化或音色质量；没有因夹具成功认定提供商和所有模型接入完成。阅读规则是确定性分组，不是语义断句模型；超长单词、重叠讲话、手改组部分可见等不能安全处理时明确拒绝。

字幕动画、采样级音频末端、内部 PTS gap、配额/历史归档、费用预算、素材语义索引、原生实时媒体、长工程整机资源与双端原生验证仍按主路线推进。帧级时间线和无真实样本计数的探测不冒充采样精确同步。
