日期：2026-10-25。状态：P4 基础链路已实施，真实 CLI 推理和完整业务质量尚未验收。关联 FW-R02/FW-R07/FW-R08/FW-R11/FW-R12/FW-R15/FW-R16/FW-R17。完整需求与媒体/发行门槛不变。

## 四类真实工作流

`internal/workflows` 将内置方法与参数编译为同一 editor.EditRequest，先在副本模拟，界面显示影响、证据、警告和原工程版本，再以保存的预览 ID 应用。前端不能修改返回命令后冒充已校验预览。应用、MCP 和手动编辑共用撤销历史。

- 口播词间停顿压缩：依照当前接受词及源指纹，以阈值、间隔保留、边缘/句末/说话人保护形成候选。只处理明确选择的完整 linked 源组，不移动未选其它轨；不把无接受文字等同于静音或语义错误。先复制保留段再修原 ID，使跨剪口的字幕人工文字/样式能继承。
- 字幕整理：批量修改明确字号、颜色、背景、对齐和位置，保留文字与来源。范围可为选择字幕/所选源的绑定字幕或明确的全部字幕。
- 已保存配音编排：使用已导入音频的真实时长和可选的既有接受词，不捏造已生成声音或字符时长。新声音继续走语音任务及费用确认。
- 已有补充镜头编排：按明确区间插入图片/视频，默认最上视频轨和静音，原音画保持。核心新增同类型 BeforeTrackID，保持其它轨相对顺序；新轨可撤销。

词间工作流首轮最多32个时间不重叠完整源组、128处候选；不支持的并行/跨组复杂组合明确拒绝。savedFrames 取实际最终工程总长差，linked 音画不双计，背景音乐长尾导致总长未缩短时明确警告。负值表示工程延长，不当作人工工时节省。

四份中文 `builtin/*/SKILL.md` 已内嵌并可按 ID 读取，描述实际前置、方法、参数、工具和范围。它们不是任意脚本执行器，也没有自动安装到用户 Codex/Claude 配置。

## 可复用参数预设

`Catalog` 提供相同参数说明、默认值、选项和范围给界面及 MCP。PresetStore 原子 JSON 保存自定义预设、固定工作流版本及乐观 baseVersion；更新/删除旧版本拒绝，失败写入不发布内存版本。内置工作流不可删除，参数拒绝未声明脚本/字段。

素材型预设可以不固定 assetId，使用时再选择当前工程资产，避免把跨工程复用伪装成所有素材 ID 自动有效。预设只保存方法参数，运行前仍需重新验证工程、实际源文件、轨道和版本。

## 本地 MCP 工具

固定官方 Go SDK v1.7.0（Go1.25），Streamable HTTP 仅监听随机127.0.0.1端口，使用临时 bearer。普通状态、工程、预设和调用记录不包含 token；只有用户显式获取连接配置时返回 HTTPHeaders。Host/Origin/peer、输入输出、并发和取消有明确限制，schema 本地解析，不加载远端引用。

连接绑定原工程实例。允许编辑是单独选择，默认只读；切换或重新打开工程后，旧 scope 在同一工程锁内拒绝读写。已允许的普通可撤销操作不逐条打断审批。工具提供摘要、分页素材/片段/源词、工作流预览和可选编辑/撤销重做，不开放任意文件路径、Shell 或模型密钥。

图像、视频、语音和导出工具只准备待核对请求。确认收费只在客户端接口，MCP 没有 approve 工具；模型 consent 和音色本人声明被清除，用户须重新确认。重复确认已 started 请求返回原持久任务。导出请求不携带输出路径，确认时用户选择。停止连接拒绝尚未确认请求，不把断开连接说成已取消远端计费。

## 外部修改与资源

客户端只初读及运行时轮询轻量状态，revision 未变不反复拉完整工程。Engine.Identity 零分配读取标量；MCP 状态不复制大型转写。Inspector 未提交草稿、旧版本提交失败和时间线拖动都保留/挂起同步，不能把旧整 Clip 配上新 revision 静默覆盖；用户明确放弃草稿后才重读。

普通 CLI 快照规划的上下文也做了明确投影：不内联全量原始/接受词，保留词数/源转写摘要，并明确指出哪些派生字幕/素材没有内联；需要内容时使用分页工具或工作流。不把省略伪装成“没有转写”，也不猜未给出的词时间。原始256KiB上限仍保留。
