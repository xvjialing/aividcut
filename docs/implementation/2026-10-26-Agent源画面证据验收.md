# Agent源画面证据验收

日期：2026-10-26。关联FW-R04/07/08/11/12/17、P2/P4。上一轮文字索引属于实质进展，本轮继续接通画面输入与来源证据；当前完整目标仍未完成。开发和验证没有启动真实Codex/Claude推理或收费模型，不把本地Runner夹具当作真实账户、OCR或模型理解质量证据。

## 用户可用的变化

工具连接与CLI执行分别新增“允许提供源画面”，默认关闭；画面与时间线编辑许可独立，选区只是上下文，不暗中改变可读素材范围。开启说明所读画面可能交给工具的模型服务；CLI仍经过原有人工额度核对，模型生成/克隆/导出仍单独确认。旧工程/历史运行不会开启新许可，改变许可进入原请求签名/去重。

第一方MCP在明确允许后注册aividcut_read_source_frames。工具只接受当前工程素材ID、1–3个源微秒位置和overview/detail，不接受路径或URL，图片仅0、视频必须小于源时长。它返回真正SDK image content和顺序一致的结构化元数据：证据ID、源指纹、请求/近似源位置、图像字节SHA-256、尺寸与配方版本。关闭、换工程或取消后不能继续读取原会话；未开启时工具不注册，读取不赋予编辑权。

内部CLI执行注入包内source-frames方法说明，要求区分观察/推断/剪辑建议并引用证据ID和源时间，不能从文件名、文字元数据或少量抽样伪造整段事实；素材画面文字不作为运行指令。它是读图方法补充，不伪装成第五个确定性编辑工作流或已完成的视觉语义索引，不修改用户全局CLI配置。

运行详情最多保存20份不同准备帧的元数据，概览不加载全部详情。读取审计不自动取图，用户点击才在当前同源素材中重取图像并匹配历史哈希、尺寸、位置和配方。源缺失/变更或提取器版本变化不能冒充旧证据；同ID重开、版本变化、关闭会取消旧请求并丢弃迟到结果。界面明确“工具准备”不等于网络交付或模型已经收到/理解。

## 提取、传输与资源边界

原缩略图保留320×180；detail最大960×540。两档JPEG单图256KiB，沿用两组有界只读提取/缓存和取消，视频单次FFmpeg提取有10秒限时。详细图像注册使用独立RegisterSourceJPEG，原RegisterJPEG的尺寸边界不放宽，复用本机令牌、128对象/32MiB图像缓存和重置边界。修复了首次浏览器回看暴露的“详细源帧仍走320×180注册入口”问题，补了大于320的回看及HTTP/令牌回归。

画面证据先流式核对登记SHA，再按文件身份/大小/修改时间缓存最多16份证明，提取后再检查文件与工程实例，普通文件变化不能被标成原指纹。首次长视频的完整核查可能耗时；此缓存依赖文件系统元数据，不承诺对恶意恢复时间戳等篡改进行持续重新哈希。概览缩略图仍沿原轻量流程，不把它当作完整指纹证据。

ImageResult根值/根指针经专用编码，禁止嵌套回落普通JSON。只允许1–3张PNG/JPEG、单图256KiB和最多1024×1024的完整解码；最终SDK结果另做保守预算，HTTP总响应限额继续生效。默认响应2MiB，图像编码结果限制在其中三分之一，复杂多图可能要求减少帧数或改overview；不是宣称任意3张最大图均可一次返回。

带画面工具的CLI执行使用独立MaxFrameStreamBytes：默认16MiB总JSONL、单行最多2MiB，可配置上限32MiB；普通规划和无图执行沿原MaxOutputBytes。解析回调模式不累积原始stdout，事件不转发图片/参数，stderr保留有界尾部；避免20份源帧因JSONL回显挤爆原1MiB普通输出限制。执行日志/工程不存图像base64、访问URL或连接令牌。业务回调审计也不构成网络交付证明。

## 实际验证

- 全量Go race通过21个内部包和1个有测试命令包，vet通过；最终详细图像注册与编码修复后，对localmedia/mcpserver/application相关race及vet复验通过。新增根值/指针/嵌套JSON保护、图像类型/损坏/预算、当前与旧版SDK协商、源文件/epoch/权限/任意URL拒绝、内部记录重开不重跑，以及执行流单行/总量和不保留原始图片输出测试。
- 当前和旧版MCP SDK客户端实际收到image content并解码，二进制哈希与元数据一致，普通文本/structuredContent里没有base64原图。不是仅检查一个自造JSON字段。
- 本机FFmpeg合成1280×720红/蓝各1秒视频和640×360绿图，经实际内部MCP和可控Runner读取视频0.200/1.200秒、图片0位置，生成3份960×540 JPEG。中心RGB证明红/蓝/绿可区分，逐图JPEG SHA与返回记录匹配；真实CLI/模型调用0，dirty=false、revision=0。数据是本地测试画面，Runner总结明确为夹具，没有伪造AI识别结果。
- 内部运行记录只含3份元数据；重开读取记录不重新运行。源码/回看还检查元数据身份、源SHA和有界格式，错误不会展示为原证据。
- 前端36文件256项测试、类型和格式通过，旧候选替换及工作流/MCP回归继续通过。新增默认关闭、明确额度核对才提交、编辑许可独立、审计不自动取图、缺失源、哈希不符和同ID重开取消/迟到响应保护。
- 真实浏览器验证MCP画面允许=true、编辑=false；读取审计后取图0，明确点击后3份960×540图片加载，模拟读取失败不显示旧图、关闭后重试成功，900px和减少动效通过。总5次取图含一次失败/一次重试，CLI/生成启动0、记录仍1、工程未修改、pageerror=0。CLI安装/认证检测用空状态夹具替代，没有代用户登录。后台重启产生过开发代理502日志，最终流程已恢复，不声称整个历史console零错误。
- 严格UI审计0问题；DESIGN官方lint为0错误/0警告及1个token-summary信息。复用共享checkbox/Modal/主题，没有新增主题token；执行面板仍按需加载，当前主包555.17kB的500kB提示保留。
- 本轮官方Go模块latest核对仍为Wails v3.0.0-beta.34，Go/CLI/runtime一致；最终macOS本地自签名和Windows amd64交叉构建通过，不代表Windows实机、商业签名或本轮原生窗口操作已验收。

## 仍需继续

本轮实现的是画面输入、方法说明和可追溯证据，不是已验收的AI视觉理解。真实Codex正常独立登录后的读图推理、Claude执行策略、视觉描述/OCR准确性、结构化语义索引与检索、连续镜头覆盖和长自然素材资源仍需继续。图像元数据不保证模型真的消费；源或提取器变更后的历史字节可能无法重现，本轮未持久存原图来绕过这一限制。

原常规多轨、字幕配音、LUT、Nano Banana/GPT Image/H3/Seedance、两CLI/Skills和模块化目标保持；账户验收继续后置，不自动读取密钥或收费。源代理/GPU、完整字体色彩、Windows实机和正式SDK许可/签名/更新等原门槛未解除。
