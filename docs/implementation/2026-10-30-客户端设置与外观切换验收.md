# 客户端设置与外观切换验收

日期：2026-10-30。对应新增需求 FW-R18，以及 FW-R12/FW-R17 的工作台交互与显示约定。

## 范围与行为

- 页头齿轮进入“设置”对话框，首期提供浅色、深色、跟随系统三个原生单选项。共用既有 Modal、Button 和弹窗焦点行为。
- 选择立即作用于工作区、侧栏、时间线、输入、弹窗、错误状态和滚动条；默认保持已有深色。跟随系统通过 matchMedia change 事件实时更新，关闭设置后继续生效。
- 偏好保存至当前客户端 WebView 的 localStorage（`aividcut.appearance`），React 挂载前恢复主题。与工程数据及撤销历史分开；无记录、非法值、不可读存储回退深色，缺少系统检测时仍可手动切换。
- 保存失败保留本次显示并提示无法保存，提供重试；失败信息在设置重开后仍保留。其它窗口更新偏好时同步。
- 颜色唯一来源继续为 tokens.css；浅色用语义变量覆盖。黑色媒体画布、成片内容颜色和现有场记板品牌配色保持独立。Canvas 波形只重绘颜色，不重新请求音频。

## 实际浏览器验证

以独立的 `/private/tmp/aividcut-appearance-data` Go 联调服务验证，未使用用户实际工程数据。

- 默认深色打开设置，点击浅色后工作区与对话框同步切换。
- 使用方向键依次切到深色、跟随系统，原生单选状态与当前外观提示同步；此 Mac 浏览器当前系统模式为浅色。
- Escape 和“完成”关闭后焦点返回 settings-trigger。
- 刷新后恢复跟随系统选择；手动浅色即时生效，再次刷新也恢复浅色。
- 900×720窗口下设置宽560、高372.54，x=170、y=173.73，控件与关闭操作全部可见；document宽900，无横向溢出。
- 同时打开并取消既有新建工程弹窗，浅色下仍使用原有字段、选择器和取消/创建布局；工程保持原状态。
- 实际计算样式：light、color-scheme=light、background=#f2f5f9，scrollbar-color=`rgb(139,154,171) rgb(237,241,246)`。切换前后工程仍为0片段、REV 0。
