# 语音应用与音轨准备验收

日期：2026-10-25。状态：P2 语音应用链路已接线，真实账户、音色质量和双端原生验收仍未完成。关联 FW-R03/FW-R04/FW-R05/FW-R11/FW-R12/FW-R15/FW-R16/FW-R17。完整产品目标不缩小。

## 已实现的使用流程

语音页包含转写、配音、音色和任务四个视图。模型连接使用已有系统凭据设施；图片/视频生成页和语音页按各自能力目录的供应商隔离，防止在错误目录中编辑连接。配置状态仍不等于账户验证。

转写选择工程中已有音视频，明确核对上传和费用后开始。应用先在本地准备音轨，再有界串行调用分块识别。每块提交前保存意图，原始响应、上传摘要、源偏移和真实覆盖分别落盘；未知提交不会自动重交。任务列表只读取摘要，展开后才取完整词详情。

成功转写由用户明确接纳到原工程，可选择同时生成绑定字幕。接纳前再次流式核对实际源文件 SHA-256，拒绝元数据未变但内容已经变化的源；等待核对时工程切换同样拒绝。普通 ApplyEdit 不开放原始转写接纳参数，不能绕过持久结果路径。

源词纠错只更新接受版本，保留词 ID、源微秒和说话人；原始识别不被改写。纠错带原工程 ID 和转写 revision，冲突保留草稿。字幕解绑需要明确动作，通过统一命令完成。接纳和绑定为一个可撤销事务，不会失败后留下半份工程修改。

配音选择账户音色与精确模型，明确提交后保存 MP3，并通过媒体探测取得真实时长与指纹。成功文件以本机签名 URL 试听，用户另行导入素材库或放入音频轨。重复导入不会复制整段配音，包括原片段已经分割且仅保留部分的情况；导入状态按当前工程核对，撤销后重新计算。

音色列表显式分页。自定义音色仅引用登记的音频样本，需要主体及本人/已授权声明，结果始终区分未验证状态，不能把供应商返回 ID 当作身份验证成功。没有自动克隆、登录或收费测试。

## 音轨准备与时间来源

媒体层只用一个 FFmpeg 解码过程顺序读取 PCM，以有界缓冲写入 16kHz、单声道、16-bit WAV 分块，不把长视频完整读入内存，也不为每块从头解码。默认五分钟一块、六小时源上限，配置最高二十四小时和1024块；单次协议上传小于64MiB。

原资产时长、真实音轨覆盖、源起点、物理样本时长和时间基准容差分别保存。视频长而音轨短时不补尾部静音上传，音轨晚起时保留源偏移；内部 PTS 断续目前明确拒绝，不将间隙压缩或伪装为已验证的连续声音。PCM 尾部采样差和容器时间基准以证据/警告表达，不按文字长度补时间。

已核查的输入包含常用容器和 raw ADTS AAC。真实合成夹具覆盖 stereo 48kHz 到 mono 16kHz、分块中不同频率、短音轨、晚起音轨、AAC 编码延迟及 Matroska 毫秒时间基准。分块边界真实语音识别质量仍需账户与语料验收。

本轮也修复了原软件导出把晚起音轨压到源零点的问题：按与实际渲染相同的源入点和时长测量首个有效音频帧，将延迟除以速度后并入既有时间线延迟，不重写视频/音量/混音/LUT/字幕链。10个晚起、裁剪、位置、半速/双倍速与导出选区场景，以及非零容器起点与Prepare覆盖一致性均通过真实媒体回归。空源区间不伪造音轨。

准备目录成功后才发布，不覆盖已有目标；失败和取消清理本次未发布结果。成功 ASR 在原始 receipts、聚合结果和成功状态都可靠保存后清理自己的 prepared WAV，重开与本地恢复只依赖保存的识别证据。部分/unknown 暂保留准备音轨，当前尚无磁盘配额或自动过期策略。

## 本地恢复与关闭

语音持久状态位于应用资料的 `speech/`，和预览缓存分开。相同任务 ID/原工程/内容返回已有记录；同 ID 不同内容或损坏记录拒绝当作新提交。ResumeSpeechLocal 只继续保存已有结果，不查询或重新 POST。无法取得同步返回内容时保留 unknown，用户核对不会被解释成自动重试。

连接被任务使用时禁止删除/改变模型，凭据租约保护运行中的读取。单独音色查询在取得凭据前建立取消/关闭作用域，并在共享锁外等待；应用关闭不会被该等待占住共享锁。图片、视频、语音和账户查询全部结束前仍保留根数据目录写入锁。
