# 本地镜头索引验收

日期：2026-10-26。关联FW-R04/07/08/11/12/15/17、P2/P4。上一轮分析接纳与检索为实质进展，本轮完成本地候选镜头覆盖和代表性取样索引，未完成原完整目标，没有真实CLI/模型推理或付费请求。

## 本轮结果

选中视频的源画面区域可展开“本地镜头索引”。默认关闭不请求，展开只查询缓存；明确检测才启动本机后台任务。阈值1–50、最短间隔1–5000毫秒整数，默认10/250ms，结果另列实际使用参数，草稿修改不冒充已检测配置。运行/排队、缓存待核对、失败和取消有独立状态；可取消，切换工程取消旧任务。任务列表显示中文“本地镜头检测”。

结果来自FFmpeg scdet的视觉变化信号，是候选，不是镜头语义、OCR或模型理解。闪光、转场、快速运动都可能触发，低变化切换也可能漏掉。每段提供真实源时段内的代表性取样位置；点击后只定位并显露侧栏原源画面/滑条，不改变主素材播放器位置或时间线，不自动播放、上传或生成。

源时序由实际解码第一帧时间与输出视频终点构成，保留晚起视频前的空窗和音频长尾之外的范围，不用容器时长补成视频内容。时间归一化沿现有FFmpeg默认输入坐标，候选需回看，不声称帧精确编辑；没有有效起止/结束回执或越界候选时失败，不返回假覆盖。

## 模块与资源

media.DetectScenes以受控本地路径/容器和协议白名单、单解码/过滤线程处理，先缩小到320×180以内、固定像素格式，再读取scdet时间；首帧showinfo只走一帧支路，避免打印全部帧。日志流式解析，总预算4MiB、单行16KiB；检测进程最多30分钟，解码错误立即失败。最多2000段候选，近邻/重复按明确最短间隔归并，取样在半开区间内。

后台复用单槽任务队列，至多8个待处理任务，不因此冻结编辑或自动调用模型。进度文字只显示实际处理到的源时间，不按耗时伪造百分比。新导出与扫描共用队列，因此重扫描会占据重计算槽；完整并行资源策略仍待后续评估。

缓存是可重建的派生JSON，不写工程Schema或Undo。键包含源SHA、导入时长、方法/参数、FFmpeg版本及工具文件身份。首次完整核查SHA后按已有源证明复用，文件身份/大小/修改时间变化后不能直接信任。冷启动只有待核对缓存，不暴露为已核对结果；用户明确核对后可复用而不重新解码。缓存至多32份、单份1MiB，原子写入，损坏/错误配置可重新检测；运行记录至多64份且切工程释放，取消/失败不会静默成为新完成结果。

文件元数据缓存不是恶意篡改防御，恢复相同大小/时间戳等极端情况不保证持续重哈希。长视频首次SHA核查和完整解码仍可能耗时；这些数据限额不等于客户端总RSS、GPU或自然大工程性能验收。

## Agent入口

第一方只读MCP新增aividcut_get_shot_index，分页最多100、默认40，只读取已完成且来源已核对的本地缓存。缺失、待核对、失败或运行中明确返回状态，不自动启动扫描，不返回路径、URL或图片。旧scope关闭后不能继续读。读实际图像仍需原独立源画面许可；方法说明要求按sampleUs核对候选，不将五点取样或变化信号当整段语义。
