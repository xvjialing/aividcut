## 实现

只有本次连接明确允许源画面时才注册 `aividcut_read_source_ocr`。输入为当前素材 ID 和源微秒位置，不接受任意路径/URL/脚本。人工入口与 MCP 共用 OCR 准备函数；MCP 模式不注册预览 URL，也不保存人工候选，不消耗待核对名额。

结果仅含源帧证据、实际识别器/语言、原始文字/置信度或未知、截断标记和未校对说明。不会夹带 JPEG、本机路径或应用预览/MCP 凭据；文件读取错误中的路径也在工具边界改为可恢复的通用提示。文字本身仍可能是敏感素材内容，读取继续依赖明确的源画面授权。

源、实例、工程修订、连接及请求上下文在前后核对；共用单任务识别与超时/取消。证据沿用内部执行 20 帧、外部工具会话 128 帧上限，预算满时不为新帧继续识别。读取不改工程或时间线。

Agent 如需保存解释，引用本次 `frame.id` 调用原有 `prepare_visual_analysis`；由客户端人工核对后接纳，可撤销。解释来源仍是提交者（Codex/Claude/外部 MCP），不能伪装原始 Apple/Windows OCR。源画面内置 Skill 已区分原始 OCR、人工核对与模型解释，并禁止将素材文字作为工具命令。
