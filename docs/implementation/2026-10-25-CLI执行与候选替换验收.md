# CLI 执行与候选替换验收

日期：2026-10-25。关联 FW-R02、FW-R03、FW-R07–FW-R12、FW-R16、FW-R17。完整目标仍在推进，本文只记录本轮真实改动和对应证据，不将局部链路当作整个产品完成。

接口定义见 [CLI 执行与候选替换接口](../specs/2026-10-25-CLI执行与候选替换接口.md)。

## 本轮改动

- 客户端新增第一方 MCP 执行队列，与旧结构计划分开。独立检查执行配置、稳定 ID、持久运行记录、取消、工具审计和结束版本；直接执行可以按已授权工程权限提交实际编辑。
- 排队期间版本变化、切工程、重开同 ID、只读、重复 ID、适配器异常和重启中断均有专门处理；不会自动重新推理或重放工具。取消保留已经完成编辑，逐批 Undo。
- 专用 MCP 随执行启动和停止。令牌只通过独立子进程环境传递；普通 DTO、运行历史和命令行不含令牌。非协作工具的晚到审计结束前保留 Agent 资料锁。
- 正常结束后可保留人工待核对请求，取消则拒绝本次 pending；请求许可按自己的工程实例和版本计算，不依赖当前 MCP 监听或后续新连接。CLI consent 不代替模型费用、音色身份或导出路径确认。
- 生成候选增加后端预览和显式替换。保持镜头 ID、轨道、起点、时长和构图，明确候选入点、速度、原声/候选声/静音与 LUT；候选导入和镜头替换在同一事务，整组撤销。
- 编辑核心允许音频片段引用确有音轨的视频素材；受控替换命令把原讲话字幕和排除记录迁到真实同源音频承载，保持字幕稳定 ID 与人工覆盖。不把旧转写附到无关新画面。普通编辑/MCP 通用命令不能直接携带音频承载或调用未校验替换。

## 已取得的证据

应用层通过 race 回归，包含官方 MCP 客户端实际访问 loopback 工具、修改与撤销、取消后保留已提交编辑、只读工具、切工程、持久去重和异常收尾；另有候选预览不修改、原子替换、Undo/Redo、陈旧版本、锁轨、候选篡改、错误身份及重开同 ID 的应用回归。

`work/execution-replacement-check/cli-metadata-evidence.json` 来自真实 Go 开发接口调用安装的 CLI 配置诊断：Codex 0.164.0 的 execution_mcp 与 execution_effective_config 均 pass，确认唯一 aividcut server、环境变量凭据引用、精确工具白名单、required、approve、read-only、never 及受限特性关闭。独立作用域 signed_out/needs_login；未创建推理 turn，也没有复制认证或登录。Claude 2.1.308 仍为 policy_unverified，未降级启动。

`work/check_execution_replacement_api.py` 使用真实 Go HTTP、媒体导入、FFmpeg 合成导出和工程保存，输入为自建 640×360、3 秒色块视频、440Hz 音调、自绘 PNG 和合成接受词；明确不是实际 ASR 或模型质量测试。结果保存在 `work/execution-replacement-check/api-evidence.json`：

- 预览不增加 revision 或素材；应用将候选导入和视觉替换一次性提交。
- 新视觉保持 90 帧，真实原视频的音频承载可渲染；原字幕绑定及人工覆盖保留。
- 替换前后导出抽取 PCM 的 RMS 均为 `0.0623811848370558`；这证明该夹具没有丢失/重复原声贡献，不扩展为全部编码与音频效果质量证明。
- 一次 Undo 恢复原视觉、字幕来源并移除本次候选导入和音频承载；保存重开能恢复替换及真实绑定。
- 真实付费供应商调用为 0。假 Provider 只产生自绘 PNG，不作为模型接入验收。

最终检查：17 个内部 Go 包的 `go test -race -count=1 ./internal/... ./cmd/...` 通过（显式开发 FFmpeg/ffprobe）；最后取消交错修复后，执行/MCP 定向 race 再次通过。`go vet` 通过。前端 108 项测试、类型、格式、构建及静态设计审计通过。主 JS 为 493.87KB/gzip153.22KB，两个新增面板按需加载；不将构建体积当作运行内存或交互性能。

## 仍需推进

真实登录账户下的 Codex 推理、Claude 有效执行策略和 Windows 进程树/运行均未完成。当前执行的多次工具提交逐批撤销，尚无跨人工编辑的整会话撤销/持久恢复；pending 人工请求只保存在当前会话，历史归档与预算台账未完成。

替换不自动拉伸短视频，也不猜复杂 linked 组、另一套讲话转写或候选已有持续字幕的归属；这些情况明确拒绝并保留原工程。静音或使用新声音时，旧字幕仍表示原讲话，需人复核内容一致性。替换预览为素材对照和结构影响，不冒充正式 LUT/字幕合成画面。
