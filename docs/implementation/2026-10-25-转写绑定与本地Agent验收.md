# 转写绑定、语音协议与本地 Agent 实施验收

日期：2026-10-25。状态：实施中，完整目标未完成。关联 FW-R02/FW-R03/FW-R04/FW-R05/FW-R07/FW-R08/FW-R11/FW-R12/FW-R15/FW-R16/FW-R17。

## 本地 Agent 应用链路

已有本地 CLI 包接入 Wails、开发 HTTP 和助手面板。界面能检测安装、独立作用域登录与隔离检查，展示仅供手动使用的登录说明、工作流前置条件、结构化操作摘要和原始命令 JSON。用户先明确调用 CLI 生成计划，再单独决定应用；计划生成过程不修改真实工程。

应用层在调用 CLI 前保存稳定请求 ID、原工程 ID/revision/内容指纹及选区。相同内容的请求重试返回已有计划；中断记录重开后不会自动再次推理。实际应用再次通过编辑核心与选区校验，作为一次可撤销事务提交。工程已经变化时拒绝旧计划，避免覆盖人工操作；已应用历史不会因 Undo 被当作新调用。

计划保存在应用资料的 `agents/plans.json`，认证由 CLI 自身管理，不复制其他作用域认证文件。临时工作目录位于系统临时目录，避免继承用户工程的 CLI 配置。关闭时取消状态检测和计划队列，worker 结束前保留临时目录与进程锁。

本次真实 Go HTTP 只读检查识别 Codex 0.164.0 与 Claude Code 2.1.308。两者在本应用独立作用域均为 signed_out；Codex 为 needs_login，Claude 为 policy_unverified。未确认的 Start 请求被拒绝，计划列表为空。证据：`work/agent-api-check/evidence.json`。这不是推理成功或两种 CLI 已完整接入的证据。

## 源转写与字幕绑定核心

工程新增持久的源转写与字幕来源：原始识别词、接受修订、源指纹/时长、说话人、字幕绑定和人工覆盖分别保存。接纳转写、纠错、生成绑定字幕、解除绑定和明确复制进入统一命令；旧 schema=1 工程以可选字段兼容。

源片段的移动、修剪、分割、变速、复制和删除通过核心派生相关字幕，并与源编辑一起撤销；人工文本/样式覆盖需要随正确的源实例继承。手动删除或解除绑定的字幕保留排除信息，防止下一次普通编辑重新生出同一字幕。相关字幕轨锁定同样约束隐式变化。

源内容指纹发生变化时转写和绑定标记陈旧，不能静默使用旧词时间。词时间与原始来源仍保留，重新取得转写另行接纳。当前首先建立逐词/短句词条派生，不将其称为完整阅读断句体验。

Agent 的选区校验已包含与所选源片段绑定的字幕，使核心合法派生不被误判为修改选区外对象；无关联的片段仍受选区保护。

## 语音适配基础

`internal/speech` 提供 ASR、TTS 和音色管理通用契约，具体实现 ElevenLabs 的 Scribe、配音、音色分页与即时创建协议。请求只引用已授权素材 ID；读取器验证本地文件、指纹、变化与输入限额。结果保留缺失时间、空格、事件和说话人，语音字节不进入普通 JSON。

同步提交出现不确定结果时不自动 POST 重试。音色创建需要用户明确声明来源及授权，创建成功不等于身份已验证。当前协议与来源见 [语音接口核查](../research/语音接口核查.md)。没有调用真实模型或创建真实音色。

- `localagent` 新增带绑定字幕的源选区测试，验证源移动的隐式字幕派生合法。
- 前端 55 项测试、类型检查和构建通过；既有生成面板继续保留，新增 Agent 测试仅注入 mock API。

## 字幕核心规模基准

设备为 Apple M5 Pro，Go1.27 darwin/arm64；固定单核、10 次、3 轮中位数。样本为真实生成的 1k/10k 绑定词字幕、2 条字幕 lane，测量移动源片段的核心提交：

| 接受词数 | 优化后 ns/op | B/op | allocs/op |
| --- | ---: | ---: | ---: |
| 1k | 2,711,829 | 4,898,545 | 63,177 |
| 10k | 24,762,392 | 47,378,816 | 630,483 |

10k 基线约 48.9ms、115.1MB 分配；通过引用索引、预分配和每源独立精确有理数映射工作区，耗时下降约 49.4%、分配字节下降约 58.8%。分配量是每次操作产生的总字节，不等于常驻内存。

该结果不包含完整进程树、50 份撤销历史驻留、桥接 JSON、React/WebView、媒体播放或多源并行。当前约 24.8ms 和 47.4MB 分配仍需后续整体资源预算验证，不能据此宣称 4K/长字幕实时编辑已验收。可复现命令与前后完整数据见 `internal/editor/README.md`。
