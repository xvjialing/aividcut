使用隔离数据 `/private/tmp/aividcut-settings-mcp-data` 的真实 Go 服务，经同一前端桥验证，没有操作用户实际工程或外部工具配置。

1. 从设置点击MCP，正确显示“工具连接未启动”，编辑和源画面两个开关默认未勾选；没有自动启动或查看凭据。
2. 显式点击“启动只读连接”，后端在随机127.0.0.1端口启动真实MCP，界面显示运行中、当前工程和版本0；编辑/源画面仍未授权，运行时开关不可更改。
3. 在外观与MCP之间往返，重新读取到同一个运行连接；停止按钮仍可用。
4. 显式停止后显示“工具连接未启动”，可再次手动启动；测试连接已停止，服务最终已关闭。没有读取或截图真实访问凭据。
5. 最终900×720窗口下document宽900，设置正文分组x=228、宽644；content视区高656、滚动内容高726，由设置正文单独滚动。只挂载一个MCP面板。
