# 本地源画面文字识别验收

2026-10-28，FW-R04/FW-R11/FW-R12/FW-R14/FW-R15，P2/P5。对应[规格](../specs/2026-10-28-本地源画面文字识别.md)和[适配器说明](../../internal/ocr/README.md)。本轮完成通用应用契约及 macOS 首个真实识别器，Windows 识别器仍未实现，完整目标继续。

## 结果

在素材源浏览器选择图片或视频位置，明确点击“识别当前画面文字”。本机 Apple Vision 独立进程识别已核对的 detail JPEG，不上传源文件。核对窗口保留源图、源位置、原始文字和置信度，可修改文字、放弃或接纳。没有文字显示空态；失败保留当前核对文字，切源/取消不接纳迟到结果。

接纳调用统一工程命令，记录 `apple-vision` 来源、`apple-vision-ocr-v1` 方法和实际源帧证据；不改变时间线。内容页可检索、回看或移除，一次 Undo 撤销。应用核对工程 ID/修订/源实例和文件指纹，拒绝缺失/变更源及旧结果；同一接纳 ID 不允许改写已提交文字，重复回执不会重放已撤销操作。

工程升级 v6，v1–v5 只在内存迁移，明确保存才改写，旧版本夹带 OCR 来源拒绝。旧客户端不能读取已保存的 v6；这是对来源契约的兼容边界，不是静默格式覆盖。

## 验收证据

- 前端 64 文件、451 项通过，新增 7 项覆盖人工核对/接纳、取消迟到结果、切源、平台不可用、失败重试/空态、文字上限与校验复位、接纳失败保留修改。类型、格式、严格 UI 静态审计及实际 production embed 检查通过。
- OCR、编辑核心、应用、存储/版本/恢复/收集、MCP 和发行检查相关竞态通过。OCR 运行中真实子进程超时取消、有界输入/输出、识别器身份、空结果、旧修订、取消先到、源缺失、幂等接纳/Undo 及 v6 迁移均已覆盖。
- 实际 Apple Vision 修订 3 探测支持简体、繁体及英文。自有中英文图片与四秒视频第 2 秒均识别出“本地文字识别”“SOURCE FRAME 120”和中文说明；空白图片 0 条。视频画面逐秒计数实际读到“SOURCE SECOND 2”，源位置 2000000us 随接纳、检索和保存重开保持。本轮实际测试没有用夹具文字替代识别器，也没有跳过。
- 实际识别把 `AIVidCut` 看成了 `AlVidCut`，保留原结果并经人工修正；这证明固定样本通过不等于通用 OCR 准确率达标。当前采用最大960×540的detail源画面，缩小可能丢失原素材细字；照片、低清文字、运动模糊、复杂版式和完整设备矩阵继续待验。
- 浏览器实际导入 → 识别 → 修正 → 接纳 → 一次撤销 → 再识别/完整修正 → 单处检索 → 源帧回看 → 保存通过。900×720 无横溢，证据窗口在可视区内。初次自动化输入曾追加到原文，已撤销并用完整替换纠正，最终保存文字逐条核对正确。
- 正式随包 macOS 副本未设置识别器覆盖路径，自动发现辅助进程，实际识别、原生文字修正、接纳和保存通过。最终构建再次重开 v6、识别并放弃，修订保持 5。原生保存文件为 2 份来源明确的分析记录，最后一份含“AIVidCut 原生核对文字”；所有测试实例最终正常退出。

## 构建与剩余范围

Mac 包包含已编译的 `AIVidCutOCR`，辅助进程与应用分别本地签名，deep/strict 校验通过；构建记录绑定源代码/产物 SHA256、Swift/SDK/目标及系统依赖，发行检查明确扫描 OCR 角色。客户端不随包分发 Swift 编译器或 Apple 系统框架。

[Windows 候选](../../work/ocr-check/AIVidCut-windows-amd64-source-ocr.zip)交叉构建、764 文件与 ZIP CRC 通过，界面如实显示当前没有 OCR 适配器；尚未在 Windows 执行。双端媒体 SDK 沿用固定内容，应用依赖声明及最终哈希匹配。静态发行检查仍 Mac 0 blocker/3 review、Windows 0/30，均 `releaseVerified=false`。

Wails [官方最新入口](https://github.com/wailsapp/wails/releases/latest)本轮仍为 [v3.0.0](https://github.com/wailsapp/wails/releases/tag/v3.0.0)，Go/CLI/runtime 保持对齐。Apple 接口依据：[文字识别请求](https://developer.apple.com/documentation/vision/vnrecognizetextrequest)、[语言校正](https://developer.apple.com/documentation/vision/vnrecognizetextrequest/useslanguagecorrection)。

未增加整段 OCR、自动字幕、向量索引或 Agent 专用 OCR 工具。图片/视频生成、ASR/TTS、Codex/Claude、Skills、LUT 和既有多轨能力保持；真实账号、Windows 适配/实机、完整目标设备性能及商业发行门槛不因本轮通过解除。此前 npm 精确版本原许可缺项仍保留，未使用其他版本文本冒充补齐。
