## 结果与范围

Seedance 从不可提交的占位改为火山方舟北京区标准 API 的具体适配，固定模型 `doubao-seedance-2-5-260628`。采用已核对的创建/查询契约，标准 API 与 Agent Plan、BytePlus 及代理渠道分开；该渠道是已说明的实施选择，不将其写成用户已确认账户或渠道。

当前三种模式为文字、首帧/首尾帧、PNG/JPEG 参考图。图生视频必须有首帧，尾帧可选；画幅仅自动跟随首帧，不能混入 reference_image。参考模式明确指定 reference 子任务，避免提示词把任务变为视频编辑。参数范围由实际适配校验，默认明确 720p、5秒、MP4、生成同步声音，允许改为无声；整数时长4–30秒，一次一个视频。仅声明 MP4，与当前结果导入器一致；不暴露尚不能保存的 MOV。

新增通用能力字段描述默认尺寸、按模式画幅、首帧要求及声音能力。前端不再硬编码封禁整个 Seedance 家族，未知型号仍不可提交；其它模型未声明声音能力时，后端拒绝声音参数，前端不注入。新接入无需复制编辑核心、任务服务或视觉主题。生成输出先保存候选，导入和替换仍由原统一编辑命令明确执行。

## 任务、核对与恢复

创建采用 Bearer 凭据、独立 POST 和顶层任务ID；查询沿原 ID 使用 GET，检查返回的 ID 和模型。queued/running/succeeded/failed/cancelled/expired 映射本地状态；未知状态、身份不符、缺少可用MP4结果不伪报完成。响应损坏或没有安全任务ID时保留 unknown，不重交POST；没有远端ID时查询也不能生成。

声音选择进入请求签名、持久请求和配方。请求/配方复制布尔值，调用方后续修改原指针不能改变已核对内容。MCP准备时显式补齐声明的默认声音，在客户端以中文展示，仍需人工核对；仅准备不会计费。未实现远端取消，停止本地等待不代表远端取消或退款。

真实适配器与持久任务的回环HTTP测试完成：确认前0次提交；提交一次后等待、关闭并重开；原ID可恢复；结果成功只下载一次，保存视频及含无声选择的recipe，工程未自动导入；修改声音重复使用原ID会冲突。下载不携带供应商凭据，journal/recipe不含密钥和签名URL。固定MP4为本地FFmpeg生成的1280×720、24fps、6帧、0.25秒H.264蓝色画面，完整解码通过；它只验证传输/保存，不代表服务商已生成所请求的5秒镜头或声音质量。
