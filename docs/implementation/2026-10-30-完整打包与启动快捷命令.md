# 完整打包与启动快捷命令

日期：2026-10-30。关联 FW-R11、FW-R12、FW-R14；范围为本机构建使用便利性，不恢复或扩大此前完整目标的待验范围。

## 用户要求与实现

用户希望简化完整打包和启动，不再每次填写 `AIVIDCUT_BUNDLE_MEDIA_RUNTIME`。该变量原本指定已装配的媒体运行库来源，包含 FFmpeg/FFprobe、MLT/Qt、worker 和数据文件；构建时复制进应用，最终用户无需配置此地址。

- `make build`：完整构建。优先显式 SDK 变量，否则使用 `work/media-runtime/<GOOS>-<GOARCH>/`，先校验，再进入原 Wails 构建。
- `make run`：完整构建成功后通过 macOS 系统打开应用，失败不会启动旧构建。
- `make open`：直接打开 `build/bin/AIVidCut.app`，不重新编译。
- `make build-app`：保留原底层应用构建。无 SDK 变量时不包含媒体运行库。
- `make dev`：沿用 Go 服务与 Vite 浏览器调试，区别于原生客户端启动。

本机现有 SDK 经原清单验证后复制到 `work/media-runtime/darwin-arm64/`，内部相对链接保持，原验证资料保留。源码不硬编码此前带中文和空格的验收目录，也不扫描旧 `.app` 猜测 SDK；新检出需首次准备匹配的媒体库，缺失给出明确位置与装配文档。`make setup` 仍只安装开发依赖和 Wails CLI。

## 当前限制

当前 SDK 为 arm64，部分 Mach-O 记录的最低系统版本为 macOS 26。主程序声明 macOS 13 不足以保证整个包可在旧系统运行；Intel 和较旧 macOS 需匹配 SDK 与实际设备验收。

快捷启动不提供热更新，也不强制关闭已有窗口；更新后先正常退出运行中的客户端再用 `make run`。`make open` 可能将已有实例带到前台。

完整 `.app` 在兼容系统运行无需安装开发环境和媒体库；模型账户、独立 CLI、用户工程/素材仍单独准备。Developer ID、公证、Windows 实机、第三方许可与完整目标收尾审计中的未达项均保留。
