# 生成任务条件同步验收

日期：2026-10-28。范围：FW-R09、FW-R10、FW-R11、FW-R12、FW-R15，P3/P5。对应[规格](../specs/2026-10-28-生成任务条件同步.md)。本阶段完成，完整产品目标继续。

## 实现结果

默认生成面板首次读取完整任务，随后携带完整视图的 SHA256 摘要；内容未变化时只返回摘要和 `changed=false`。变化及手动刷新返回完整列表，清空明确返回 `jobs=[]`。原 List/MCP 契约保留。列表转换现在每次只复制一次工程快照，文件检查期间释放编辑锁。

每次仍核对生成文件的路径、类型、大小及工程导入状态，文件缺失、撤销、归档和还原会改变摘要。全部任务元数据继续参与未知请求检查与跨页比较。迟到列表不更新数据或摘要，本地操作回执使摘要失效，下一次完整核对；同步错误保留旧任务，成功后仅清理同步提示，保留其他操作错误。
