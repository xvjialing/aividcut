# 当前画面参考素材验收

日期：2026-10-26。关联FW-R01/04/09/10/11/12/17、P1/P3/P4。见[规格](../specs/2026-10-26-当前画面参考素材.md)和[数字证据](2026-10-26-当前画面参考素材-evidence.json)。本轮补齐产品规划中的“使用当前帧”，局部验收通过；完整目标继续进行，账户验收按用户指令后置。

## 用户可用行为

预览区“使用当前画面”暂停播放并打开生成页的本机取图工具。工作区预览传入工程播放头，源图片/视频预览传入源素材及其实际预览位置；音频不提供取图。打开入口只准备参数，不保存图片或提交生成。

面板明确区分两种来源。时间线合成读取原片并以工程全精度输出PNG，包含图层、文字、字幕、变换和LUT，不使用实时低精度或源代理。源素材取样沿用详细源帧接口，输出最高960×540 JPEG，明确为近似源位置，不包含时间线效果；静态图片的位置固定为零。

用户确认来源与位置后，才将图片保存为普通素材。保存走共享工程串行通道，先处理属性草稿与编辑冲突，单次add_asset可一次撤销/重做，不自动上轨。结果显示实际图片与尺寸；没有配置模型连接也能完成本机准备。失败保留参数和原操作ID，可重试；运行中可以取消本次取图。

支持参考图的当前模式可明确点击“选用刚保存的画面”。图生视频将其选为首帧，其它支持参考图的模式在能力上限内追加；不会因保存图片自动改提示词或提交任务。参考角色仍受现有能力契约和核对流程约束，尾帧可在原选择器中指定。新取图面板按需加载，位于既有generation-form滚动区，与付费生成表单分别拥有操作入口，避免取图输入回车触发生成核对。

## 核心、持久化与重复请求

CaptureFrameAsset接受操作ID、projectId、projectRevision、sourceEpoch及明确的源位置或工程帧，拒绝混合参数。服务同一时刻只执行一个取图，总时限45秒；换工程、退出、明确取消均结束旧操作。开始、来源核查后和最终导入前检查工程实例、版本与源文件，失败不写入部分工程结果。重复返回也复查实例和取消状态。

时间线合成复用原生离线渲染会话，固定full并清空VisualSources；未配置原生引擎时走既有FFmpeg全精度路径，工具缺失/不支持效果如实失败。实际返回帧号、原画幅和RGBA长度必须一致。已有LUT素材可能没有内容指纹，本次只对本地来源副本补算SHA用于取图证明，不偷偷更改工程素材。全部被时间线引用的源均核对，缺失源拒绝，即使其当前不在取图时刻生效。

图片实际探测后受小于50,000,000字节、最多32,000,000像素预算约束。先在私有临时目录完成，核对来源和当前工程后再移动、执行统一add_asset。成品位于持久资料的frame-captures目录，独立于预览/代理缓存；取消或导入失败清理未提交目录。已登记图片不会被清理预览缓存删除。

origin.json保留frame-capture-v1、原输入、工程哈希、各源指纹、实际素材及渲染方式，不保存本地访问能力URL、base64或凭据。同ID重试验证参数、文件位置、普通文件类型与完整SHA；成功后返回当前工程状态，Undo后的旧请求不重新导入。完成标记写入异常时仍返回实际成功结果并附提示，避免已经修改工程却报告完全失败。工程仍为SchemaVersion 2，图片是普通素材，来源清单是应用伴随资料。

## 限制与仍需继续

源JPEG为取样参考，时间精度和像素不同于原片全精度；本轮不做HDR/广色域或透明度端到端一致性保证。FFmpeg回退路径只沿用既有能力，本轮实际LUT/中文字幕验收使用原生引擎。图层、旋转及4K有浏览器成品证据，不将所有自然媒体、变速/旋转组合都标为新覆盖。

来源清单存于应用资料，不作为可移植工程打包；跨电脑仍需要随素材迁移并重新链接。已有成品保留供Undo/Redo使用，本轮没有新增永久删除素材与回收策略。极大工程的完整源核查可能耗时，当前以单任务和总时限给出明确失败，不宣称即时取图。

新功能原生窗口本轮未补操作，先前Mac锁屏和Windows实机条件仍待；浏览器、单元测试与交叉构建不替代双端实机。真实模型接收图片、图像/视频质量、成本及真实CLI推理继续按用户要求后置，本轮付费/模型/真实CLI调用为零。完整多轨剪辑、字幕配音、LUT、四类模型、两种CLI、Skills、资源/色彩/商业发行范围保持。
