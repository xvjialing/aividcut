## 真实发现的两个缺口

第一次使用官方部署工具已复制多数依赖，但保留少量@rpath及开发机搜索路径，不能认为退出0即可移植。独立改写后，未签Resource中全部MLT `.so`导致进程被系统终止；codesign --deep的整包核验并不自动替代对每个此类资源代码的重新签名。现先逐个Mach-O签名，再签嵌套app，最后生成内容清单。只用本地ad-hoc，不读取用户私钥。

签名修复后，禁止读取Homebrew时出现registered media decoder unavailable。实际使用loader生产者需要MLT数据目录中的loader.dict等运行文件，只有模块和profiles不够。因此清单v2增加data入口，拷贝完整MLT数据；playback.Config新增MLTDataPath并显式传MLT_DATA，自动设置从已验证清单取路径，手动开发可用AIVIDCUT_MLT_DATA。不是移除解码器检查来通过测试。

清单v1继续可读且不能夹带data语义，v2必须声明数据入口；用户媒体设置仍为独立v2，Project仍v4。原生环境覆盖任一worker/repository/profiles/data时不暗混随包其它原生路径。检测和保存继续使用真实选定数据目录，自动设置不保存安装位置。
