日期：2026-10-25。状态：P3 应用链路与界面已实现，类型/组件/构建验证通过；真实账号与双端实机尚未通过。关联需求：FW-R09、FW-R10、FW-R11、FW-R14、FW-R15、FW-R16、FW-R17。完整产品范围和阶段顺序保持不变。

## 本次落实的行为

模型连接保存名称、服务商和精确模型，凭据通过惰性的系统存储访问：macOS Keychain、Windows WinCred。启动、列表与健康信息只读非秘密元数据；不在启动时弹出钥匙串读取。连接配置状态仅表示已保存，不表示账号权限已经验证。

生成请求先固定 ID、目标工程和参数，再保存队列与提交状态，随后才执行一次供应商 Submit。同 ID 同内容返回已有任务；并发、窗口重开和工程 revision 增加不会产生第二次提交。相同 ID 不同内容及损坏的已有记录拒绝作为新任务使用。

用户停止的是本机等待。尚未提交的排队任务可明确取消；已有远端 ID 的任务保留等待与恢复入口；同步提交结果未知时保留 unknown，用户核对服务记录后可以标记已核对，不会自动重交。恢复异步任务只查询原 ID，下载地址失效时重新获取原任务的地址。

结果按任务目录原子发布，保存配方和文件指纹。成功表示素材已经落盘；用户另行选择加入原工程的素材库。单个、部分或整组候选都经真实格式、大小、SHA-256 和媒体元数据验证，然后通过统一工程命令提交，可整批撤销。任务展示按当前工程重新计算导入状态，因此撤销、重做和切换工程不会沿用过期的“已导入”标记。

根数据目录和生成任务目录由操作系统排他锁保护。关闭取消等待，但极慢的 worker 结束前仍保留锁，另一实例不能提前改写资料或重新接管请求。已完成任务中的媒体、远端查询 ID 和配方不会因清理预览缓存而丢失。

## 模块与数据位置

| 模块 | 职责 |
| --- | --- |
| `internal/connections` | 非秘密连接资料、凭据租约、轮换、已提交清理警告与跨重启清理意图 |
| `internal/generation` | 模型能力、输入校验、供应商协议、参考文件和本地结果发布 |
| `internal/generationjobs` | 持久状态、稳定请求 ID、去重、取消等待与恢复 |
| `internal/statefilelock` | macOS/Linux 文件锁与 Windows 区域锁；内核随进程退出释放 |
| `internal/application/generation.go` | 应用权限边界、签名素材 URL、原目标工程及可撤销导入 |
| `app.go` / `cmd/devserver` | Wails 与开发 HTTP 使用同一应用方法 |

桌面默认将持久资料放在 `os.UserConfigDir()/AIVidCut`，预览缓存放在 `os.UserCacheDir()/AIVidCut/previews`。`AIVIDCUT_DATA_DIR` 可指定独立开发目录，预览放在该目录的 `previews`。开发 HTTP 的 `-data` 包含连接元数据、生成记录、结果和预览；正式运行不依赖开发服务器。

连接 JSON 不含 API Key，任务 JSON 不含 API Key、内联图像字节或带签名的远端下载 URL。系统凭据替换先保存清理意图，再发布新引用；发布已完成而旧凭据清理失败时返回成功资料和 warning，界面应清空密码输入，并提供显式清理重试。

未完成或未核对任务关联的连接不能删除或改变模型；等待中的任务允许同服务同模型换 Key，以便更新失效凭据后查询原任务。正在使用的凭据租约阻止运行中替换。
