# 语音接口核查

日期：2026-10-25。关联 FW-R03/FW-R04/FW-R05/FW-R11。目的为本轮适配的协议依据，不等于真实账户、地区、配额或语音质量已经验收。

## 当前实施选择

本轮新增通用的 ASR、TTS 和音色接口，先实现 ElevenLabs 的 `scribe_v2`、`eleven_multilingual_v2`、音色分页和即时音色创建。供应商仍为实施候选，不记作用户已确认的商业合作方；用户明确的图片/视频及两种 CLI 目标不变。

Scribe 接口返回词、空格和音频事件，能够附带词/字时间与说话人。适配层保留这些差异和缺失时间，不按文本长度制造时间戳。[创建转写](https://elevenlabs.io/docs/api-reference/speech-to-text/convert)

配音按准确 voice ID 与 model ID 提交，返回文件再由应用核查真实时长。音色由账户列表分页取得；克隆返回的供应商验证字段与本产品验证状态分开保存，不把创建成功显示成已验证身份。[创建语音](https://elevenlabs.io/docs/api-reference/text-to-speech/convert)、[创建 IVC 音色](https://elevenlabs.io/docs/api-reference/voices/ivc/create)

输入当前限于显式登记的本地素材，不接受自由 URL；客户端总上传限制为 64MiB。它是当前资源边界，不是长视频转写目标的替代。长素材的音频提取、分块、全源偏移与重组需在应用层补齐。

## OpenAI 时间戳兼容情况

本次查阅的官方文件转写指南将 `gpt-transcribe` 作为新录音转写推荐，同时说明旧模型及时间戳兼容示例将在 2027-02-26 退役。因此不能只看通用请求字段就认为新模型已经提供剪辑所需的词级时间，也不将旧 Whisper 接口作为新项目的长期默认。[文件转写指南](https://developers.openai.com/api/docs/guides/speech-to-text)、[转写请求参考](https://developers.openai.com/api/reference/resources/audio/subresources/transcriptions/methods/create)

OpenAI 配音与自定义声音仍可作为后续适配候选。自定义声音有账户资格、录音与确认要求，不能把普通声音参数当作音色创建流程。[配音指南](https://developers.openai.com/api/docs/guides/text-to-speech)

## 证据边界

`internal/speech` 的 HTTP fixture 仅证明请求/响应、时间校验、授权素材读取、未知提交及限额行为。没有上传用户素材、创建真实音色或进行真实配音。应用持久任务、连接设置、长素材处理、音频真实时长、字幕接受界面及质量测试尚需继续完成。
