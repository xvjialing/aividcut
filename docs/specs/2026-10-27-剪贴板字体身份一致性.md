# 剪贴板字体身份一致性

2026-10-27，FW-R01/FW-R03/FW-R11/FW-R12，P1/P2。补齐已存在的工程字体与剪贴板组合，沿原统一命令和媒体验证，不增加跨工程/跨序列粘贴或素材写入权限。

复制的文字、单独字幕以及随源复制的绑定字幕，都需把TextStyle.FontAssetID引用的字体登记为快照所需资源。冻结的是Asset身份/字体元信息与指纹，内容不含TTF字节，仍沿64MiB快照预算。默认字体引用为空时保持现有行为。

首次执行粘贴前，字体与普通素材/LUT使用同一身份核对；同一素材ID但不同指纹/元信息明确拒绝，缺失也在生成副本前拒绝。失败不能留下片段、改变修订或新增撤销记录，并保留原剪贴板。路径、名称、临时URL及Missing状态不作为内容身份，已验证的同内容重定位继续允许，副本保留原字体引用。

同ID工程的不同文件/版本可以具有不同的共享素材内容；重开仍需原有projectId/sourceEpoch/baseRevision校验，不能仅因projectId或fontAssetId相同就当作同一字体。应用普通编辑继续禁止直接add/update_asset，导入/重定位与打开文件的校验保持，不为测试或修复开放绕过接口。

保持单次粘贴事务、Undo/Redo、幂等回执、字幕手改/来源/排除词与MCP摘要隔离。只给私有快照补全引用，不改工程v5或持久格式。实际文件仍由字体模块/媒体链路在读取时验证SHA和元信息，核心身份比较不冒充磁盘字节读取。

验收覆盖先复现后修复、三种复制形式的字体内容变化拒绝、缺失/原子性/历史、同内容重定位/一次撤销与重做、应用重开同ID工程，以及实际TTF移动原文件、删除原片段、粘贴后保存重开的30帧RGBA一致性。相关Go竞态/静态检查和双端构建同步；Windows实机、任意字体/自然语料与完整发行继续后续验证。
