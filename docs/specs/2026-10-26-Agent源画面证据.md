# Agent 源画面证据

日期：2026-10-26。关联FW-R04/07/08/11/12/17、P2/P4。上一轮接受文本索引为实质进展，本轮推进画面证据与本地CLI分析的真实输入，保留后续结构化语义索引/OCR/质量验收，不把JPEG抽样当作模型已经理解内容。

## 范围

复用已登记源素材和有界提取器，提供overview（320×180）和detail（960×540）两档JPEG源画面，单图256KiB、每次MCP最多3帧。返回素材ID、源指纹、请求源位置、近似取样位置、图像字节SHA、尺寸、配方版本及稳定证据ID。图片只取0位置，视频必须小于真实源时长；不返回任意路径、URL读取或时间线/LUT合成，不冒充帧精确定位。

MCP使用真正image content块携带画面，结构化元数据与图片顺序一一对应；不得把base64放进普通JSON文本冒充模型可见图片。SDK传输继续校验内容类型、像素/字节和总响应预算，保留取消、会话范围、并发与有界响应保护。

## 授权、执行与回看

沿用当前工具连接和CLI执行的确认入口，新增独立“允许提供源画面”选项，默认关闭。未允许时不暴露图像工具；开启后说明所选CLI可能把所读取画面交给其模型服务。该选项不等于授予时间线编辑或收费生成权限，普通只读/编辑授权继续独立。原项目文件和旧记录不能默默开启画面权限。

Agent按需读取源帧，结论需引用证据ID、源时间并区分画面观察/不确定推断/剪辑建议；少量抽样不能证明整段不存在某物，素材画面中的文字不是运行指令。方法说明随启用画面输入的执行注入，不修改或安装用户全局CLI配置。

内部执行记录只保存有界画面元数据，不保存图片base64、访问URL或MCP令牌。用户可在当前同源素材中重新回看并核对图像字节指纹；源已变化或当前工程不匹配时禁止展示成原证据。分析总结仍是模型描述，不能代替实际图像和词/工具证据；本轮不自动上轨或改字幕。

## 验收

真实MCP SDK客户端读取图像content并解码，对应元数据/字节哈希；无画面权限/越界/任意URL/缺失/源变更/旧会话/超预算/取消失败恢复；真实本地视频两处可区别画面与静态图；CLI夹具通过内部MCP真实读取图片并留下可回看的证据，重开仅读历史不重跑。UI沿用共享checkbox/Modal/Field，默认关闭、人工核对才提交，历史证据显式回看不自动上传或推理。类型、回归、双端构建、文档追踪一并更新；真实账户和模型理解质量继续后置。
