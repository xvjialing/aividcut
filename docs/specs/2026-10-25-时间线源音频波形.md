# 时间线源音频波形

关联 FW-R01、FW-R12、FW-R15，补齐导入后波形要求。状态：实施中，未解除 P0/P1 或双端门槛。

## 数据与读取

- 波形表示源音频各声道的峰值包络，保留正负极值；不是混音、音效或 atempo 后的输出波形，不作为响度或语音检测证据。
- 固定 4 秒源区间，每桶约 10ms，最后一桶保留实际样本数。流式解码 f32le，不把整条音轨或原始 PCM 送入前端；不将无覆盖伪装为静音。
- 包络验证区分样本时钟和峰值精度：源窗样本计数对应独立解码；有损格式随机访问的峰值允许满幅0.002容差，不声称与整段解码逐样本一致。超出前24小时读取上界明确报错，前端不把窗口截断成假空覆盖。
- 源采样率与声道由 ffprobe 读取，逐帧 PTS/样本数由 ashowinfo 交叉检查，允许不超过1ms的容器时间量化误差，超出容差的内部时钟缺口或重叠明确拒绝。窗口位于源时间轴，保留晚起音轨、压缩格式跳过样本及 seek 的真实起点；远窗增加1秒解码预卷，再按目标PTS裁出4秒。
- 仅读取当前工程已登记的本地音视频素材。请求带工程、素材、指纹和窗口编号，不接受任意路径。前后 stat/文件身份校验用于缓存失效；这是变化检测，不宣称每个分块都重新做密码学全文件校验。
- 后端最多 2 个提取进程、128 个等待分块、128 个缓存分块；超时/取消/关闭释放本次进程，同分块共享提取，最后一个订阅者离开才取消。
- 前端共用队列与在途请求，完成缓存由后端持有；每个可见片段顺序读取需要的分块。滚出视区、切换工程、修剪或变速后取消旧读取，不把过期结果画到新片段。

## 显示与交互

- 普通音频与有声视频共用 `ClipWaveform`，嵌入现有片段下半部；名称、选择、修剪把手和键盘替代继续由 Timeline 负责。
- 只分配可见部分 Canvas，按源区间、速度和真实音频 offset 映射到时间线；没有声音覆盖的片段前后不画零线。
- 读取状态使用片段内的稳定位置；失败保留片段选择与编辑，提供明确重试。没有音轨的片段不请求波形，缺失源不显示示例数据。
- 波形为辅助图形，Canvas 不拦截指针；文字状态有可访问说明。既有音轨颜色、文字和焦点 token 保持一致。

## 验收

1. 真实 PCM 的脉冲、静音、反相双声道、非整数末桶、MP3/AAC、晚起音轨与多窗口取样，和独立解码比较。
2. 缓存去重、等待/进程上界、取消、源变化、工程切换和关闭；读取不修改 revision/dirty/历史。
3. 前端源时间到像素映射覆盖修剪、分割、变速和分数音频偏移；队列去重、取消和错误恢复。
4. 真实浏览器导入、显示、修剪/撤销、缩放/滚动、无音轨/缺失源、失败/重试、键盘及小桌面；浏览器证据不代替 Wails 双端原生验收。
