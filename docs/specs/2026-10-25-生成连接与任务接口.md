# 生成连接与任务接口

状态：实施中。目标：将已有 provider 适配接入真实应用，不把本地 HTTP fixture 当作真实账号验收。当前不自动发起收费调用。

## 连接

- `GetConnections()` → Profile[]。
- `SaveConnection({id?,providerId,name,modelId,apiKey?})` → Profile。
- `DeleteConnection(id)` → `{warning?:string}`，逻辑删除已提交但旧凭据清理失败时说明。
- `GetConnectionHealth()` → `{pendingCleanup:number, storage:string}`，只读元数据，不访问密钥。
- `CleanupCredentials()` → `{pendingCleanup:number}`，显式重试本应用旧凭据清理。

Profile 为 `{id,providerId,name,modelId,configured,createdAt,updatedAt,warning?}`，不含密钥或凭据 handle。warning 表示已提交配置后的清理提示，不应被误判为保存失败或继续留存表单密钥。配置状态只表示已保存，不表示账号/模型权限已验证。密钥只经本地桥传给系统凭据存储，不写工程或配方；正在使用的连接不能替换/删除。

## 能力与生成

- `GetGenerationCatalog()` → `generation.Capability[]`，来源 `internal/generation/model.go`。
- `SubmitGeneration({connectionId,request,consent})` → GenerationJob。
- `ListGenerationJobs()` → GenerationJob[]。
- `StopGenerationWaiting(id)` → GenerationJob，语义是停止本机等待，不宣称远端已取消。
- `ResumeGeneration(id)` → GenerationJob，只重查已有远端任务或重取已有结果，不重新 POST。
- `ImportGenerationResult(id)` → Bootstrap，将已落盘结果加入原目标工程素材库；不会自动替换镜头。
- `ImportGenerationAssets(id,assetIds)` → Bootstrap，显式只导入所选候选；空列表拒绝。
- `AcknowledgeGenerationUnknown(id)` → GenerationJob，仅记录用户已核对无法恢复的未知结果，不声称取消远端，也不重新提交。

request 完全沿用 `generation.Request` 的 camelCase 字段；ID 由客户端先生成，后端以它和请求内容去重。Connection 的 provider/model 必须与请求一致。consent=true 只由明确的用户“生成”操作传入，表示这一个请求的服务商、模型、数量、参考素材与计费动作已展示；不替代未来 MCP 的预算/授权策略。

GenerationJob：

```typescript
type GenerationJob = {
  id: string;
  connectionId: string;
  projectId: string;
  projectRevision: number;
  request: GenerationRequest;
  status: 'queued' | 'submitting' | 'running' | 'waiting' | 'importing' | 'succeeded' | 'failed' | 'unknown' | 'cancelled';
  message: string;
  remoteId?: string;
  createdAt: string;
  updatedAt: string;
  canResume: boolean;
  acknowledged?: boolean;
  assets: Array<{id:string;kind:string;name:string;path:string;url?:string;mime:string;sha256:string;bytes:number;recipeId:string}>;
  imported: boolean;
  importedAssetIds?: string[];
};
```

任务元数据持久化。中断的同步提交在结果未知时保持 unknown，不自动重交；有远端 ID 的视频任务可进入 waiting 并由用户恢复查询。最终结果落盘后才成功。成功返回只代表素材已保存，`imported` 单独说明是否加入目标工程。

`imported=true` 表示整组候选已加入当前原目标工程；部分候选由 importedAssetIds 标记，剩余候选仍可导入。该状态以当前工程重新核对，Undo 后可回到未导入。完整本地结果优先恢复，不因凭据失效而强制查询远端；同步字节在文件提交前丢失且无可查询 ID 时直接 unknown。

## 界面约束

新增模型连接设置与生成面板，复用公共组件和当前工作区，不重构其他视觉。密钥输入默认遮盖，保存/取消后清理内存表单值，不在日志/toast显示。按能力提供模式和参数；Seedance 未验证保持禁用并说明。

参考图片来自当前工程已登记 PNG/JPEG；OpenAI/Google 编辑可使用 role=reference_image，H3 video.image 仅 first_frame/last_frame，video.reference 使用 reference_image，模式互斥。暂未开放音频/视频参考，不把同一用途套给所有模型。

生成按钮明确提示按提供商规则计费，不编造价格或进度；默认数量1。任务支持停止本地等待、恢复已有查询和加入素材库。无法恢复的 unknown 同步请求不能用“重试”按钮偷偷重交。当前 app 协议未提供自动替换镜头，用户可继续用统一编辑命令处理导入素材。
