# 可调预览合成精度

关联FW-R01、FW-R11、FW-R12、FW-R15、FW-R17。状态：已实现并完成局部验收，完整平台与资源仍待；证据见[可调精度验收](../implementation/2026-10-25-可调预览合成精度验收.md)。P0–P6完整范围不变。本轮让高分辨率工程能主动降低合成负担，完整源代理与GPU路线仍按原计划推进。

## 行为

实时预览增加全、半、四分之一精度，全精度保持原默认。用户改变精度时暂停并重新准备当前帧；选择仅影响当前预览会话，不进入工程、revision、dirty或撤销。画面是较低合成精度的近似结果，核对文字细节、色彩和最终输出可回到全精度。界面使用共享Select，加载、失败和重新准备沿用现有模式。

独立导出始终使用原画幅与全精度，不受预览选择影响；低精度不能扩大原先不支持的工程语义或隐藏原始字体/素材问题。原路径的画面输出上限和WebView二进制预算保留。

## 实现约束

- 保持Project原快照，通过只读派生副本缩放合成画幅、图像平移及文字/字幕几何；字体按实际最终像素字号缩放，固定边距与字幕下边距同样缩放。旋转、相对缩放、LUT参数和原素材保持；像素取整产生的预览差异明确属于近似精度。
- 原工程先执行完整语义检查和真实文字测量；图窗口使用同一派生精度，不能只缩首窗或重置源时间。
- 帧率、开始/持续帧、音频采样率、AudioRange、SourcePhase、源入点/速度和混音保持原数据。低精度逐帧PCM必须与全精度字节一致，定位仍按全局工程时钟。
- 只接受full/half/quarter枚举；过小画幅明确拒绝，不静默改变选择。导出入口重置full，内部离线会话拒绝非全精度配置。

## 验收

1. 静态编译验证几何/字体/边距、原快照不变、未知值和小画幅拒绝；原始不支持语义不能被低精度掩盖。
2. 实际原生图片/视频、旋转、LUT、字幕、分割、变速和多图窗，画面尺寸和内容符合对应精度；PCM逐帧字节相等，帧序/声音锚点相等。
3. 固定4K负载按相同帧数测准备、拉帧和进程RSS，保留环境、样本及统计，不能外推整机或自然素材容量。
4. 真实UI切换、定位、暂停重准备、错误恢复、键盘与窄窗口，当前工程不变；预览降低精度后实际导出仍为原画幅。相关测试/构建/设计和文档检查通过，双端原生仍单独验收。
