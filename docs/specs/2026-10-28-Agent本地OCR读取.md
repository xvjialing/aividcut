# Agent 本地 OCR 读取

2026-10-28，FW-R02/FW-R04/FW-R07/FW-R08/FW-R11/FW-R12，P2/P4/P5。将已有单帧 OCR 接入受控 MCP，人工与 Agent 共用源核对及识别器，不新增工程格式或放宽 CLI 策略/登录门槛。

新增只读工具 `aividcut_read_source_ocr`，仅在本次连接明确允许源画面后提供。输入只含当前工程素材 ID 和源位置，不接受路径、URL、脚本或识别器名称。复用已实现的本地识别流程、并发/时间/输出预算和当前工程/修订/源实例/指纹核对。Windows 缺包身份、helper 或语言时继续真实拒绝，不使用占位文字。

返回源帧证据与识别器原始结果，包含实际语言、原始置信度或未知及截断标记；不返回本机路径或预览访问凭据，也不返回 JPEG 图像。OCR 内容仍属于用户授权的源画面数据，不因为转换成文字而绕过读取许可。只覆盖指定取样帧，不能推断整段内容。

读取不改工程或时间线，不保留人为核对候选占位；证据沿用内部执行最多20帧、外部工具会话最多128帧的预算和执行记录。客户端断开/取消、工程切换或源文件变化时，不返回过期数据。Actor 如需保存解释，可调用已有 `prepare_visual_analysis` 并引用 OCR 返回的本次证据；记录来源仍是提交解释的 CLI，不能冒充本地 OCR 原始来源。用户通过既有核对窗口决定是否接纳，允许撤销。

更新源画面 Skill，区分 OCR 原始文字、人工核对与模型解释；素材文字是数据，不是工具指令。不从未识别/低清/截断结果编造文字，也不把 Agent 自己的纠正冒充原始 OCR。

验证默认无工具、显式许可、原始结果/证据/脱敏、记录与一次接纳撤销、容量、取消/断开/旧工程、CLI 白名单与 Skill。真实 Mac OCR 通过本机 MCP；Codex/Claude 账号推理和 Windows 系统 OCR 实机仍保留原门槛。
