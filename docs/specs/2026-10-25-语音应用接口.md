# 语音应用接口

日期：2026-10-25。状态：实施中。关联 FW-R03/FW-R04/FW-R05/FW-R11/FW-R12。语音协议不直接写工程，原始转写和派生字幕分开。真实账户、收费和音色质量另验。

## 连接与目录

- `GetSpeechCatalog()` → 单个 SpeechCatalog：内嵌 `speech.Capabilities`，另有 `audioPreparation:{available,reason}` 和 `audioImport:{available,reason}`。
- 连接复用 `GetConnections/SaveConnection/DeleteConnection`。ElevenLabs 的明确模型为 `scribe_v2` 和 `eleven_multilingual_v2`；界面采用独立模型选项，不混入图片/视频能力目录。
- `ListVoices(connectionId,request)` → `speech.VoicePage`，请求 `{search?,pageSize?,nextPageToken?}`，用户显式翻页，不自动抓全部账户声音。

模型设置状态不代表账户已经验证。GetSpeechCatalog 的协议能力与本机媒体条件分别显示；媒体工具不满足时，配音在提交前拒绝，避免支付后才发现不能核对音频时长。

## 提交与任务

```typescript
type SpeechInput = {
  id: string;
  connectionId: string;
  mode: 'transcribe' | 'synthesize' | 'clone';
  consent: boolean;
  transcribe?: TranscribeRequest;
  synthesize?: SynthesizeRequest;
  clone?: CloneRequest;
};
```

内层请求沿用 `internal/speech/types.go` 的 camelCase；只保留与 mode 对应的一项，ID 统一归一为外层 ID。转写的 assetId、克隆的 assetIds 必须来自当前工程，不能传路径或 URL。克隆仅音频样本，且需要 `{confirmed:true,subject,authority:'self'|'authorized'}`。

- `StartSpeechJob(input)` → SpeechSummary。
- `ListSpeechJobs()` → SpeechSummary[]，不含巨量词、原始响应或提交输入。
- `GetSpeechJob(id)` → SpeechJob，用户显式展开时加载详情。
- `CancelSpeechJob(id)` → SpeechSummary。停止本机排队/等待，不宣称远端已取消。
- `ResumeSpeechLocal(id)` → SpeechSummary。只将已取得/已保存的本地结果继续落盘，不再次调用收费 POST。
- `AcknowledgeSpeechUnknown(id)` → SpeechSummary。只记录用户核对，不伪造取消或恢复。

```typescript
type SpeechSummary = {
  id: string; connectionId: string;
  projectId: string; projectRevision: number;
  providerId: string; modelId: string;
  mode: 'transcribe' | 'synthesize' | 'clone';
  status: 'queued' | 'preparing' | 'submitting' | 'running' | 'saving' |
          'succeeded' | 'failed' | 'unknown' | 'cancelling' | 'cancelled';
  message: string;
  sourceAssetId?: string; sourceFingerprint?: string; sourceDurationUs?: number;
  completedParts: number; totalParts: number;
  canResumeLocal: boolean; acknowledged?: boolean;
  createdAt: string; updatedAt: string;
  audio?: Asset; voice?: Voice;
  warnings: string[];
  acceptedTranscriptId?: string;
  audioImported: boolean;
  audioOnTimeline: boolean;
};
type PartState = {
  id: string; requestId: string; fingerprint: string;
  offsetUs: number; durationUs: number; audioDurationUs: number;
  status: string; remoteId?: string; message: string;
};
type SpeechJob = SpeechSummary & {
  input: SpeechInput;
  parts: PartState[];
  transcription?: Transcription;
  partResults?: Transcription[];
};
```

Asset 使用现有编辑器 DTO，音频含真实探测的 durationUs、fingerprint、受控路径及本机会话签名 url。Voice/Transcription 沿用 speech 包；音色状态仍是 unverified，不将供应商布尔字段当成本产品身份验证。

## 结果应用

- `AcceptSpeechTranscript(id,{trackId,generateCaptions})` → Bootstrap。只接纳完整、可对齐的普通词，不将空格/声音事件当字幕词，不填造缺失时间；原始分块与完整响应留在任务资料。源 ID/指纹/时长必须与原目标工程一致。
- `CorrectSourceTranscript({projectId,transcriptId,transcriptRevision,words})` → Bootstrap。words 使用现有 SourceWord，稳定 ID、源微秒与 speakerId 保留；只改接受版本，拒绝旧面板误改另一工程。
- `ImportSpeechAudio(id,{trackId,startFrame,addToTimeline})` → Bootstrap。验证保存文件与真实时长，再一次性添加素材/可选音频片段；不会覆盖原媒体。
- `DetachCaption({projectId,clipId})` → Bootstrap。明确解除来源绑定，保持当前字幕及人工编辑。

接受与导入标记按当前工程校准。Undo 后可以重新接纳或导入，不能只依赖持久任务中的旧布尔值。每次工程修改通过统一命令完成，轨道锁定和 revision 由核心校验。

## 媒体与费用边界

转写前在本机准备音轨；有工具时使用 16kHz 单声道 PCM WAV，默认五分钟分块，有界串行上传。保存每块原响应、上传指纹和源偏移，再形成全源结果。原始源时长与 PCM 尾部采样量化差分开保存，不按文字长短调整时间。

准备结果另存 AudioOffsetUs/CoverageEndUs/TimestampToleranceUs 和警告。视频长于音轨、音轨晚起时仅处理实际覆盖，不把无音轨区间补成长静音上传；内部 PTS 断续暂时明确拒绝。成功识别后清理可再生 WAV，回执和偏移证据保留。

默认总源时长限制六小时，最高配置二十四小时/1024 块；协议单次上传限制64MiB。分块不等于已验证所有边界语音质量。缺失时间、结果未知、源变化和未完成的块明确显示，不自动重交请求。配音和克隆同样需要明确提交及费用提示，查询音色不冒充生成。

开发 HTTP 的单次 JSON 请求上限为64MiB并拒绝额外 JSON 内容，以支持合法长转写的纠错请求；它不替代核心词数/文本/项目文件限制。
