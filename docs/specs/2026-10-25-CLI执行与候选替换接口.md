# CLI 执行与生成候选替换接口

日期：2026-10-25。关联 FW-R02、FW-R03、FW-R07–FW-R12、FW-R16、FW-R17。状态：实施与验收中。保留原多轨、语音、LUT 和模型范围，本规格不替代完整路线图。

## 本轮范围

将客户端内 CLI 从只读结构计划扩展为第一方 MCP 执行会话；同时将已保存的生成候选通过预览替换当前视觉镜头。两者都沿用 Go 工程核心、revision、锁轨和撤销，不直接改工程文件。

原结构计划模式继续保持无 MCP、先校验后单独应用的含义。执行模式单独检查工具与配置，不能沿用规划模式的隔离结论。

## CLI 执行接口

- `GetAgentExecutionStatus()`：返回两种 CLI 的执行模式安装、登录和隔离证据；只读配置诊断，不推理。
- `StartAgentExecution({id,provider,projectId,projectRevision,instruction,workflow,selection,allowEdits,consent})`：稳定 ID 登记意图后进入本地队列；需要本次明确额度与工程权限确认。
- `ListAgentExecutions()`：返回不含审计详情的运行摘要。
- `GetAgentExecution(id)`：读取单次运行和最多 80 项工具审计。
- `CancelAgentExecution(id)`：停止等待和进程，撤销本次工具连接；已经完成的编辑保留，可按批撤销。

运行状态：queued、running、cancelling、succeeded、failed、cancelled、interrupted。运行记录包含开始工程版本、结束版本、工作流、选区、消息、总结、警告和工具调用名称/结果/版本/时间。不保存工具参数、访问令牌或原始认证日志。

本轮执行许可覆盖整个当前工程；选区是任务上下文，不声称是安全边界。只读会话不注册编辑工具。内嵌的四份中文 Skill 是方法说明，不执行其中脚本，也不安装进用户 CLI 配置。

本次执行专用 MCP 自动启动，不能静默接管已存在的手工 MCP。固定原工程实例，排队期间工程改变会拒绝启动；重开同 ID 工程也不能继续沿用旧连接。CLI 只接入第一方工具，MCP 凭据仅放在子进程环境，不放入命令行、公开 DTO 或持久记录。不修改用户全局配置，不复制认证文件，保留 CLI 原有正常登录流程与管理策略约束。

先落盘执行意图，稳定 ID/内容重试返回已有运行，内容不同拒绝；重开时中断运行标为 interrupted，可能已有部分编辑，绝不自动重新推理或重放工具。最多 1000 条、16MiB，历史归档界面仍待实现。

多次工具提交分别使用统一编辑事务和撤销；当前不将任意长会话伪装成一个原子事务，也不在取消时回滚穿插的人工编辑。CLI 自述总结不能代替工具审计和工程实际结果。

## 付费及写出请求的人工核对

执行 consent 只授权 CLI 本次额度和所选工程权限，不授权模型生成、音色克隆或写出路径。MCP 仅准备请求，客户端继续人工确认。

正常执行结束会停止 MCP 监听，同时保留待核对请求。取消或显式停止连接会拒绝本次 pending 请求。请求新增 executionId、canApprove、approvalReason；许可按请求自己的原工程实例、精确 revision 和授权计算，不借用当前 MCP 连接状态。后续新连接不抹掉旧的待核对请求；原工程改变后旧请求不能收费。提交时再次校验，重复确认返回原持久任务 ID。

每连接最多 40 条，全会话最多 200 条；只回收已处理旧记录，不自动删除未确认请求。pending 仍只保存在当前应用会话，真实生成/语音任务分别持久化；该列表尚不是长期费用台账。

## 候选替换接口

- `PreviewGenerationReplacement({jobId,candidateId,clipId,projectId,projectRevision,sourceInUs,audioMode,lutMode,speedMode})`：不修改工程，返回后端预览 ID、原镜头/候选元数据、保持时序、影响和警告。
- `ApplyGenerationReplacement(previewId)`：只接受后端保存的预览 ID；重新验证原工程、版本、文件指纹与候选身份，一次提交并支持整组撤销。

只支持当前生成任务原工程的视频/图片镜头。候选需要本机成功文件、正确 MIME、SHA-256、真实探测参数与受控目录；即使此前导入也重新验证。候选添加和镜头替换在同一个编辑事务中，预览不先行导入素材。

保持片段 ID、轨道、起点和持续帧数，未选片段不移动。候选源入点默认 0。speedMode=preserve 沿原视频速度，normal 明确设为 1x；静态图固定 1x。视频不足源余量拒绝，不暗中补帧、循环或变速。保留 Transform；LUT 明确 keep/clear，不用新素材的默认色彩处理冒充已验证一致。

音频策略：keep_original 保留真实原声；内嵌原声需要真实同源音频 carrier，已有 linked 声轨不重复。use_candidate 仅在候选确有音轨时可选，明确处理相关原 linked 声音。mute 静音相关声音。绑定字幕仍需关联真实原讲话来源，人工文本、样式和字幕轨保留；不能因替换画面让原话转写绑定到无关候选。锁轨、字幕锁、复杂关联或不足源区间不允许部分成功。

后端预览只在当前进程缓存，最多 80 份。参数或工程变化后重新预览；应用过的同一预览 ID 不会在 Undo 后重放。原媒体文件始终非破坏。

## 验收要求

1. 官方 MCP 客户端从执行适配器访问真实 loopback 服务器，实际编辑、审计、停止和撤销可验证。
2. 重复 ID、重启中断、排队后变更、取消已提交编辑、适配器异常、只读工具及切工程均有针对回归。
3. 正常结束后的人工请求仍可单次确认，取消、旧工程、旧 revision 不会提交收费任务；不使用真实付费账号代替本地回归。
4. 替换的预览无修改，候选导入和替换整组 Undo；原声/字幕载体、linked、人工覆盖、静音、LUT、速度和锁轨由语义测试验证。
5. 前端检查真实状态、草稿冲突、预览失效和键盘；不能靠卸载 Inspector 丢弃未提交草稿后继续执行。
6. 实际 CLI 版本配置诊断、浏览器全栈联调、双端构建分别保留证据；真实账户、Windows/macOS 实机和专业媒体性能仍按主路线验收。
