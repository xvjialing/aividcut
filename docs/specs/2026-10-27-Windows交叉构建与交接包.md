# Windows交叉构建与交接包

2026-10-27，FW-R11/FW-R14/FW-R16，P0/P5构建交付阶段。用户明确暂时没有Windows机器，先完成可交接的Windows构建链路。真实模型账户继续后置，原FW-R01–17/P0–P6目标保留。

## 范围

使用操作者明确提供的宿主MinGW UCRT编译器、sysroot、宿主pkg-config和固定MSYS2 UCRT64包锁，在macOS构建本项目完整六源文件worker。必须保留Qt Gui/Widgets文字处理和FFmpeg音视频能力，不用其它PE冒充worker。普通和延迟导入继续由统一装配器解析。

开发提取范围与运行提取范围分别显式选择。默认runtime不变；development仅从锁中MLT、FFmpeg、Qt6 base/svg四个根包取得普通头文件、导入库、pkg-config、Qt mkspecs和许可，不下载或执行目标SDK工具、安装脚本。沿用摘要、归档边界、限额、路径和新目录保护。开发SDK不是完整Windows原生工具前缀。

## 构建约束

交叉入口只接受绝对路径，编译器目标必须为x86_64-w64-mingw32，crtdefs.h中的_UCRT探针必须通过。源列表从现有CMake读取，格式变化须明确处理；Qt不是可静默关闭的选项。清除宿主编译、动态加载器和登录凭据环境，pkg-config路径只能落在明确SDK内；拒绝外部include/lib、响应文件和未支持的驱动参数。

构建和候选输出必须为新目录，二者不能嵌套；候选父目录预先存在。失败保留日志，成功记录工具/源码/产物SHA、版本、完整参数和Windows未执行状态。编译产物检查PE amd64，但该检查不等于运行时ABI或DLL加载通过。

装配器输出为包含media子目录的候选根，Wails的AIVIDCUT_BUNDLE_MEDIA_RUNTIME必须指向其media子目录，不能把候选根误当SDK根。Wails、Go和npm运行时继续使用项目固定的3.0.0正式版。

## 交接与验收

提供Windows amd64客户端、完整随包media清单v2、Windows清单核验工具、固定运行库包锁、实际许可文本及中文说明。核验随包内容、目录移动后的摘要、归档文件完整性；不得把静态扫描或Mac上构建称为Windows播放验收。

后续实机至少验证WebView2/启动、worker inspect、Qt离屏与中文字体、视频/图像/PCM、字幕/LUT、保存重开/导出、取消、资源与安装更新。模型推理、操作系统授权和正式签名/许可闭包继续独立验收。windowsExecutionVerified和releaseVerified保持false。
