# 时间线可见区与轨道索引

关联FW-R01、FW-R12、FW-R15、FW-R17。状态：实施中，完整P0/P1保持。

## 范围与行为

- Timeline仍为唯一轨道与片段交互所有者，Go保持编辑、revision、锁轨、源区间和撤销权威。前端索引只查询读模型，不自行修改工程。
- 工程片段变化时建立按轨道的区间索引；滚动只查询可见轨道与时间范围。查询保留原始片段顺序，覆盖长片段、切口、相邻短片段及最小显示宽度。刻度从可见起止直接生成，不为长工程先创建整条刻度数组。
- 标题与内容使用同一纵向滚动所有者及66px行高，完整滚动高度保留，挂载可见行及少量预留行。轨道类型编号按整个工程计算，不能随窗口重新从1开始。
- 水平与纵向滚动合并到一帧一次的视区更新，播放头继续独立订阅时钟，不让全React树逐帧渲染。
- 正在拖动与获得键盘焦点的轨道/片段暂时保留DOM，避免滚出视区时丢失capture或焦点。拖动考虑滚动偏移；结束后恢复正常裁剪。普通滚动不自动改变选择。
- 通过外部入口选择片段时定位到其轨道与时间范围；已选片段仍可显式“定位选中片段”。轨道键盘导航需能跨越未挂载行，不因虚拟化跳过工程中的轨道。
- 删除轨道/片段或重开工程后收敛越界视区与焦点；失败和锁定语义沿用已有组件，不能用虚拟化绕过草稿或外部版本保护。

## 验收

1. 区间查询与暴力参考对照：随机/长片段/半开边界/最小宽度/原始顺序/空轨道/稳定编号；查询有访问计数用以验证确实跳过不可见节点。
2. DOM验证多轨可见行上界、远滚、重新编号、外部选择、键盘跨行、焦点与拖动保留、横纵滚动补偿、删除/重开、锁定与旧版本保护。
3. 真实浏览器使用100/1000/10000片段及多轨固定工程，记录实际挂载数量、滚动/定位/缩放/编辑和恢复；保留加载/空白/失败、小桌面、键盘与减少动态状态证据。
4. 类型/单元/格式/生产构建、设计审计及双端构建。浏览器结果不冒充Wails双端原生或完整工程性能完成。
