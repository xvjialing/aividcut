# 本地源画面文字识别

2026-10-28，FW-R04/FW-R11/FW-R12/FW-R14/FW-R15，P2/P5。补齐现有素材分析的 OCR 入口，所有既有剪辑、生成、字幕和 Agent 目标保持。

从素材源画面浏览器明确识别当前位置的中英文文字；首个适配器使用 macOS 13+ Apple Vision，独立随包进程只接收本机已核对的 JPEG，不联网或读取任意外部路径。Windows 继续共用契约，未提供实际适配器时明确不可用。不得将占位结果冒充 OCR。构建必须带上进程、签名与声明材料，不能引入运行时 Swift 或 Python 依赖。

取样沿用 detail 源画面与指纹/工程实例核对。单次最多 50 条、每条最多 1000 字，进程输入/输出和运行时间有界，一次只运行一个识别；可取消、关闭退出和源变化时拒绝旧结果。展示实际取样位置、图片、文字、原始置信度和截断说明；没有文字时保持空态。用户可修正文字或放弃，只有明确接纳才经统一命令写工程，允许一次撤销；不生成字幕或改变时间线。

接纳保留源画面证据、识别器来源和方法版本，沿用内容检索/回看/移除、素材收集与保存。工程升级 v6，读取 v1–v5 时迁移但不重写原文件，旧版本夹带 OCR 来源拒绝；旧客户端将拒绝 v6。识别只覆盖选定帧，不能推断整段视频已无遗漏地识别。

验证实际中英文/无字图片、视频非零源位置、取消/超时/旧回复、接纳修改/Undo/保存重开/检索和来源不可伪造，及双端构建。保留真实 OS/模型质量与 Windows 未验证边界。参考 Apple 官方 [VNRecognizeTextRequest](https://developer.apple.com/documentation/vision/vnrecognizetextrequest)、[语言校正](https://developer.apple.com/documentation/vision/vnrecognizetextrequest/useslanguagecorrection)。
