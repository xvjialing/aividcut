# 导出编码资源档位

2026-10-27，FW-R01/FW-R11/FW-R12/FW-R15，推进P0导出资源控制。上一阶段已观察到固定4K导出RSS约953MiB，主要来自FFmpeg编码。本轮以相同工程实测后提供明确的可选档位，不把一次样本当所有设备的内存上限。

标准/缺省档位保持当前编码参数。较低内存仅支持H.264软件编码，通过受控单线程与较小预读队列减少编码缓存；不降低输出画幅、帧数或改变音频链，但可能更慢、文件大小和压缩画质可能变化。硬件或MPEG-4不支持时界面禁用并切回标准，后端明确拒绝不兼容请求，不静默忽略。无需修改工程格式。

人工、Wails/HTTP、MCP请求均走统一白名单策略，不能传任意FFmpeg参数。外部请求必须展示档位及其实际含义，仍由人确认输出；未知/不兼容参数在建立任务/媒体进程前拒绝。取消、提交保护、无覆盖与原片保护保留。

验收使用同源无损YUV参考核对压缩差异、90帧/3.003秒与PCM/字幕/LUT/源相位、固定同参数进程采样，至少重复三次比较。标准输出不因档位功能改变，较低内存明确报告占用/耗时/压缩取舍；复杂/自然长片、整机/Windows实机及完整目标继续。
