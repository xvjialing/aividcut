# 配音时间与阅读字幕接口

日期：2026-10-25。关联 FW-R03、FW-R05、FW-R07、FW-R08、FW-R11、FW-R12、FW-R15、FW-R17。状态：实施与验收中。旧普通配音与逐词字幕保持兼容，不将本轮当作完整语音质量或媒体性能验收。

## 带时间配音

`speech.SynthesizeRequest` 新增可选 `withTiming`。false/未指定继续普通配音；true 显式调用带时间端点一次，适配器需同时声明能力并实现 TimedTTSProvider。不支持时在提交前拒绝，不自动回退普通端点、识别端点或再次 POST。

原文 alignment 和朗读规范化 normalizedAlignment 分开保存。缺失时间仍为 null，畸形数组或无法映射的原始 JSON 保留供核对；有合法音频时允许音频独立成功，不因为字幕时间坏了而诱发重新付费。

Summary 新增 timingRequested、timingAvailable、timingComplete、timingReason，以及 normalizedTimingAvailable、normalizedTimingComplete、normalizedTimingReason。它们表示时间结构，不能证明文字匹配或已适合绑定。Job 详情新增 timing，保留两套数组、可空时间、警告及必要的原始字段 JSON，音频字节不进入公共 DTO。

回执将时间摘要与原 job、operation、provider、model、voice、音频 SHA 关联；journal 在保存回执前持久时间摘要。恢复校验两份摘要与真实音频，不再次获取凭据、生成或 POST。旧普通回执继续兼容。没有真实样本计数源时 SampleCount 保持 null，不从时长推算为实测值。

## 配音时间的应用可用性

`GetSpeechJob` 新增 `timingChoices:[{source,available,reason,text,wordCount}]`，source 为 original 或 normalized，按实际请求和本机音频时长校验：

- original 字符拼接必须精确等于提交原文；normalized 允许规范化数字或缩写，但只在明确选择后使用。
- 数组齐全、有界、有限、非负、有序，且时间在已探测音频内；缺失不补零，不裁切越界或按文字比例插值。
- 英文字母按实际连续字符形成源词，中文和其它文本保留供应商项；空格、标点及组合字形保留文本，词区间来自真实字符边界。
- 不能形成有效词时间时只禁字幕，原音频仍可独立导入。不会从另一套对齐补洞。

完整对齐在任务中保留；工程中的派生源词以 origin=tts、timingSource=original|normalized 标记。它们是配音时间证据，不是素材语音识别结果。旧 origin 为空的工程兼容，ASR 新接纳明确 origin=asr。

## 音频与字幕上轨

`ImportSpeechAudio(id, options)` 继续返回 Bootstrap，新增：

```typescript
type Options = {
  trackId: string;
  startFrame: number;
  addToTimeline: boolean;
  generateCaptions?: boolean;
  captionTrackId?: string;
  captionLayout?: CaptionLayout;
  alignmentSource?: 'original' | 'normalized';
};
```

generateCaptions=false 时不携带字幕参数。true 时，音频素材、音轨片段、配音时间源词和字幕通过一次工程事务提交，可整组 Undo；失败不部分导入。当前工程需为原目标工程，文件指纹和真实时长重新核对，关闭或取消后不提交。

已经有该配音素材的任意音频片段时不重复插入，已分割或删除左半段也适用；此时原片段位置不改。字幕持续规则作用于该素材全部已上轨片段，包括分割后的有效范围，界面明确说明。没有上轨且不选择上轨时，不生成空目标字幕。

Summary.acceptedTranscriptId 与 captionTimingSource 由当前工程计算；Undo 后不沿用旧任务标志。已接纳来源不能被重复 Import 换成另一套文本；已有活动字幕的轨道/排版变化走专用预览，保留人工修订。普通音频任务没有时间证据时仍能单独导入，不自动发起 ASR。

## 阅读分句

```typescript
type CaptionLayout = {
  mode: 'word' | 'readable';
  maxCharsPerLine?: number;
  maxLines?: number;
  maxDurationUs?: number;
  pauseThresholdUs?: number;
};
```

旧 nil 默认逐词；显式 word 恢复逐词。readable 零值归一为每行18字、2行、单组4秒、停顿700毫秒。界面按秒、字、行输入，后端使用整数微秒。可配置范围由编辑核心统一校验，应用层不复制默认算法。

CaptionBinding.WordIDs 支持真实有序多词。分组考虑实际词序、标点、停顿、说话人、长度与时长；字幕时间为可见词真实范围的帧外包，不以稿件估算。源词本身不因排版而改写。

人工改字、样式或布局的既有组是保护边界，完整可见时保留组与人工修改；不静默合并、拆分或丢失。trim/split 导致只剩部分保护组且无法判断人工内容归属时，原子拒绝并提示先明确边界或解除绑定。普通无覆盖组随移动、修剪、复制、变速和真实原声替换继续派生。删除和解除绑定的排除记录不能被重新分句复活。

## 排版预览与应用

- `PreviewCaptionLayout({projectId,projectRevision,transcriptId,transcriptRevision,trackId?,createNewTrack?,layout})` → `{id,projectId,projectRevision,transcriptId,transcriptRevision,layout,summary,beforeCount,afterCount,protectedCount,warnings,captions,truncated,createdAt,applied}`。
- `ApplyCaptionLayout(previewId)` → Bootstrap。

预览不改工程，最多返回200个字幕样例，同时统计全部真实影响。后端缓存80份有限计划，只收 ID 应用；重新核对原工程实例、版本、内容和源文件指纹。应用一次可撤销；Undo 后同一已应用预览不自动重放。项目切换后不将预览用于另一工程，即使 ID 相同。

未指定轨道默认沿用已启用的字幕轨；明确 createNewTrack=true 才在已有规则下新建目标轨，不能同时传已有 trackId。新轨和字幕重排在同一事务，不在预览时创建。

MCP 新增 aividcut_preview_caption_layout，以及仅可编辑连接提供的 aividcut_apply_caption_layout；读取转写摘要/接受词同时返回 origin、timingSource 和 captionLayout。普通 ApplyEdit、结构计划及通用 MCP 编辑不接收未经核对的 CaptionLayout 字段。

## 验收与限制

需要验证一次 POST、本地恢复不重发、缺失时间仍可导音频、原文匹配、明确朗读来源、同源全部片段、不重复配音、手改保护、分组跟随、锁轨、原子撤销、保存重开、陈旧预览和真实媒体/浏览器流程。fixture 和真实账户质量分别记录。

采样级音频末端、完整字幕动画、字体与色彩一致性、真实模型语音质量、费用预算/历史配额和双端实机仍按原路线推进；本轮不把字符时间或帧级片段宣称为采样精确媒体引擎。
