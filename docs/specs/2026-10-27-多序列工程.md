# 多序列工程

2026-10-27，FW-R01/FW-R03/FW-R07/FW-R08/FW-R11/FW-R12/FW-R14/FW-R17，P1。落实现有路线图中的Project/Sequence模型，原完整目标、账户及Windows实机后置不变。

工程共享Asset与素材画面分析；每个序列独立画幅/帧率/采样率、轨道、片段、源词接受版本及派生字幕。复制序列保留源词证据、字体/LUT、精确音尾、淡化、锁轨和内部引用，后续字幕纠错/剪辑互不改写。最多32个序列，不支持嵌套序列；其它序列通过全工程版本/收集/恢复保存。

schema v5保留根上的当前序列字段，新增当前序列ID/名称、稳定顺序和其它序列状态；每个序列只保存一份，不复制共享素材。单序列默认ID为sequence-main、名称为主时间线；v1–v4无损读入，旧格式夹带多序列字段拒绝，只有明确保存才改写文件。完整校验覆盖全部序列，包括非当前序列的素材引用和锁轨。

支持新建空序列、复制指定序列、重命名、切换和核对删除。新建/复制后进入新序列，创建/复制/重命名/删除各一次工程事务及Undo；删除最后一个序列拒绝，有锁定轨道的序列先切入解锁。删除当前序列后进入按稳定顺序的首个剩余序列。普通切换不生成Undo、不清Redo、不改变工程内容dirty，但递增修订并更新当前编辑上下文；明确保存时记住当前序列，重开使用上次保存的序列。

切换先稳定输入并暂停，播放头归零、选区和时间区间清除。更新SourceEpoch，原MCP/Agent执行工具和已准备写入失效，不能因复制序列的相同局部片段ID写错目标。剪贴板保留来源序列身份；本阶段仅允许在来源序列粘贴，返回来源序列可继续使用。复制序列是创建独立版本的完整操作，不将跨序列粘贴或嵌套伪装为已实现。

素材重定位是全工程同内容路径修复；影响元数据的素材变化必须核对其它序列的锁轨和有效源范围。预览和导出只消费当前序列，导出/长期任务固定启动快照，不随切换改变。Bootstrap仅下发当前序列详细数据及全部序列摘要，避免前端为其它序列复制全部片段。保存、版本、恢复和收集使用完整快照。

UI沿共享PanelTabs/Select/Modal/Field/Input/Button及现有导航/草稿保护。时间线上方直接显示可横向滚动的序列标签，支持全部32项；方向键/Home/End只移焦，回车/空格激活，当前项不重复提交，在途禁止重复操作。此manual变体适合需要准备媒体的序列导航；其它轻量面板保持automatic。每个标签关联当前时间线面板，长名称提供完整可访问名称和管理入口，不仅依赖悬停。序列管理显示数量、画幅、帧率、片段数和当前项，删除明确名称与可撤销后果。错误保留名称/选择及解释，旧范围请求不得覆盖新序列。非当前序列只读摘要，名称与ID不混用。

验收覆盖旧工程迁移、新建/复制/切换/删除/重命名、全局Undo/Redo与导航dirty、局部相同ID隔离、字幕/相位/淡化/字体/LUT保留、跨序列锁轨、旧MCP/预览/剪贴板拒绝、完整保存/版本/恢复/收集、不同画幅帧率的真实音画和导出、界面成功/失败/键盘/窄窗口及双端构建。整体目标不因本阶段通过而标为完成。
