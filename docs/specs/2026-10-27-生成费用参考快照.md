# 生成费用参考快照

2026-10-27，FW-R09/FW-R10/FW-R11/FW-R12，P3/P5。补齐路线图首版范围中的成本估算。实际供应商报价和账户验收继续后置，本轮不调用模型。

用户可在核对单次生成时选填参考单价，明确 CNY/USD 及每次请求、每张图片或每秒视频的单位。界面根据数量或显式视频秒数计算金额，提交时 Go 重新计算并冻结到任务记录。单价采用十进制字符串、最多六位小数，乘法用整数，避免浮点金额误差；不转换汇率或合计不同币种。

默认未填写，界面显示“未填写费用参考”，不把未知金额当零。价格为用户针对当前连接、模型和参数核对的手动参考，不是供应商报价、账单、预算授权或费用上限。提示词、参考素材、连接、模型及参数变化后清空本次参考价，防止误沿用；结果配方复用不带回旧单价。核对窗口冻结同一份参考价和生成请求，修改需返回重新核对。

每秒视频单位要求请求显式提供正整数时长，不推测服务商默认时长；按图片单位只用于图片模式。按请求单位数量始终为一，覆盖用户已取得整个请求估价的情况。服务商实际计费还可能包含输入、输出、声音、质量及渠道规则，单价应按当前请求核对。最多九位整数和六位小数，单次计价数量最多一百万；计算和存储均核对范围。

估价留在本地任务，不进入供应商请求、生成 Recipe、工程素材或凭据。任务失败、等待、取消或未知仍保留提交时估价，不据任务状态推断已扣款或退款。MCP 发起任务沿同一个生成核心，未提供人为核对的估价时保持未知，模型不得据参考价获得额外支付权限。

前端失败重试缓存按工程隔离，切换工程不继承旧请求编号或单价。估价纳入请求去重签名；同一 ID 改单价不得再次提交。无估价保留旧版签名及 v1 记录兼容；有估价使用 v2 记录，加载时重新计算金额和数量。篡改或损坏记录继续占住原 ID，不能静默当作新任务重交。
