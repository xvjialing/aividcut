# Windows运行库包锁与补齐

2026-10-27，FW-R11/FW-R14/FW-R16，P0 Windows SDK来源可复现。上一轮静态扫描仍有114条缺引用。本轮从显式官方仓库快照建立DLL到包映射，逐步补运行文件，不把它代替编译SDK、本项目worker或Windows媒体实机。

新增只读plan/明确apply工具：输入ucrt64.db和ucrt64.files、静态缺DLL清单与根包，记录快照摘要、包名/版本/官方URL/下载大小/SHA256及明确提供者选择。只支持MSYS2 UCRT64官方HTTPS来源，不读取/执行仓库元数据或安装脚本中的指令，不从其它剪辑软件复制库。PGP签名未验证时明确记录false。

快照中的主包修订可能变化，先在新目录重取同一快照根包、再扫描、再按缺项锁提供者；不得把旧二进制缺项与新库混合。同名DLL多个提供者必须保留冲突，核对声明后明确选包；无提供者或快照版本不一致拒绝重放，不猜第一个候选。

apply默认不发生，只有明确命令读取已锁包。下载内容按大小与摘要核验后才解压，缓存重用也需核验；只提取普通运行DLL、FFmpeg/FFprobe、MLT/Qt插件、MLT数据和许可文本，不执行Windows程序或包安装脚本，不安装到系统。SDK工具别名/编译器不属于此运行库缓存，原生构建继续需要完整同ABI开发前缀。

新输出必须不存在，隔离stage完成后才提交，错误保留stage供核对；不覆盖已有SDK。归档路径/设备名/越根/特殊文件/同名不同内容及限额均失败。索引64MiB级输入、归档解压1GiB、每下载包256MiB、下载和运行内容2GiB、256包/16384运行文件。输出包含同一来源锁，不表示签名、ABI、所有动态加载或可发行。

需要真实官方文件的迭代扫描，保留每轮缺项和最终闭包结果。DLL静态零缺项时也仍要求真实worker编译、Windows Qt字体/中文路径/声音/LUT/导出、设备/取消、签名安装与商业许可。Wails v3继续保持本轮官方latest，模型账户按用户要求后置，原FW-R01–17/P0–P6范围不缩小。

锁、静态扫描和重放结果均保留releaseVerified=false；PGP签名未验不能当发布者认证，运行集合也不代替开发SDK或Windows实机。
