## 首轮边界与接口

模块路径：`aividcut`。统一数据类型由 `internal/editor/model.go` 定义，JSON 使用 camelCase。时间线按工程整数帧，素材入点按微秒，速度与帧率用有理数。顶层 tracks 按视觉叠放顺序排列；四类轨道为 video、audio、text、caption。

工程核心公开接口：`NewProject(name string) Project`、`NewEngine(Project) (*Engine, error)`、`Snapshot() Project`、`Apply(EditRequest) (Project, error)`、`Undo() (Project, error)`、`Redo() (Project, error)`、`CanUndo() bool`、`CanRedo() bool`。持久化接口在 `internal/projectstore` 中提供 `Save(path string, Project) error`、`Load(path string) (Project, error)`。

命令：add_asset、add_track、update_track、delete_track（只允许空轨）、add_clip、update_clip（完整片段替换）、delete_clip、split_clip（atFrame 是绝对工程帧）、update_project（名称；已有内容时不能静默改帧率）。批次原子提交，检查 baseRevision 与 idempotencyKey，锁轨和源区间由核心验证。相同幂等请求返回结果，不重复编辑；撤销/重做的 revision 仍递增。视频片段自带声音时按同一片段播放，独立音画片段可用 linkGroup 关联。

## 桌面与前端桥接

Wails 主类型为 `main.App`。前端通过单一 bridge 适配调用：

- `GetBootstrap()` → `{project, projectPath, dirty, canUndo, canRedo, capabilities}`。
- `NewProject(name)`、`OpenProject()`、`SaveProject()`、`SaveProjectAs()`、`ImportMedia()`、`ImportPaths(paths)`、`ImportLUT()`、`ApplyEdit(request)`、`Undo()`、`Redo()` → 与 GetBootstrap 相同结构。
- `ExportVideo({path?, preset?, fromFrame?, toFrame?})` → Job。
- `ListJobs()` → Job[]，`CancelJob(id)` → Job。
- `GetPreviewFrame(frame)` → `{url, frame, revision}`，用于低频合成检查，不作为最终实时预览已达标的证据。

`capabilities` 至少包含 ffmpeg、ffprobe、nativePlayback、exportVideo、previewFrame 和对应原因；未具备能力的控件禁用并解释，不能显示假成功。Job 使用 `{id,type,status,progress?,message,outputPath?,createdAt}`，status 为 queued/running/succeeded/failed/cancelled。界面不展示虚构完成百分比。

导入素材后，返回 Asset.url（由受限的本地素材服务提供）。浏览器开发与 Wails 共用同一前端 bridge；开发 HTTP 适配只用于运行和测试真实 Go 服务，不能在正式版静默切换成假工程。

## 任务划分

- 工程核心：`internal/editor`（除既定 model.go 外可按契约扩展）、`internal/projectstore` 和相关测试。
- 媒体模块：`internal/media`，负责真实探测、LUT、合成/导出、能力检查和媒体验证证据，不写主入口或前端。
- 前端：`frontend/`、DESIGN.md 与 UX-CONTRACT.md；遵循此契约，普通交互与高频绘制分层。
- 主线程：Wails 入口、桥接/任务服务、依赖整合、实际运行和阶段文档。

## 验收

用真实媒体而非假路径验证导入与预览；分割、移动、修剪、文字与轨道控制进入统一命令；保存重开、撤销和重复请求有测试；原生壳可构建运行。媒体合成和导出以实际编码结果核查；原生多轨实时预览、Windows 实机、ASR/TTS/模型与 CLI 尚未完成时明确记录，不用窄测试宣称全范围完成。
