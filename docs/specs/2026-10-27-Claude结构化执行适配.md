# Claude结构化执行适配

2026-10-27，FW-R07/FW-R08/FW-R11/FW-R12/FW-R16，推进P4/P5双CLI。当前Claude Code2.1.308已被发现但Execute只有Codex路径。本轮补齐Claude独立调用/结构化事件处理与受控内部回归，不将未完成的管理策略门槛改为可运行；真实账号推理继续后置。

调用仅使用临时独立CWD、正常独立CLAUDE_CONFIG_DIR认证作用域、print/stream-json/verbose、restricted、空内置tools、明确第一方allowedTools、strict单一MCP、关闭会话持久化/自定义命令和不响应额外权限提示。safe-mode会禁用MCP，不用于执行构造；不使用bare、bypass或复制凭据。token只通过子进程环境供MCP HTTP header引用，不能进入argv、提示词或公开DTO。禁用自动工具搜索以保持固定白名单；CLI权限并非操作系统沙箱。

Claude适配独立于Codex事件解析。需要有效system/init，核对CLI版本、cwd、permissionMode、唯一已连接第一方MCP和精确工具集，拒绝非空自定义skills/plugins及子agent流。完成assistant消息只接受已知内容类型；工具调用必须匹配白名单并具备唯一ID，工具结果要对应已见调用，进度/终态与同一session关联。未知事件、hooks事件、权限拒绝、调用未完成或不成功终态不得当成成功；思考、工具参数/结果、图像数据和原始错误不进入事件日志。

不要求Claude写总结文件：从结构化成功终态读取有界UTF8总结；缺失/截断/重复终态及无init拒绝。Codex仍核对流与原总结文件，二者互不降级。取消、超时、行/总字节限额沿已有进程组和流式捕获，共用工具侧核心校验/逐批撤销，已提交操作不自动回滚。模型总结不是编辑验收证据。

生产InspectExecution仍为policy_unverified：未证明启动前有效managed hooks/工具策略，不能靠收到init后才发现异常来预防启动hooks。不增加用户绕过开关或新测试注入API。内部私有fixture才可提供已核验inspector，验证协议、第一方MCP真实HTTP往返与核心编辑/Undo；这不等于Claude真实模型已成功执行。

验收覆盖命令白名单/env与token、init/会话/工具与结果关联、未知/内置/外部工具、错误/拒绝/缺失终态、重复事件、洪泛与取消、图像不保留、受控SDK-MCP调用及核心编辑、生产门槛继续拒绝、Codex回归、Wails版本与双端构建。真实账户/CLI推理和完整macOS/Windows策略边界仍待验证。
