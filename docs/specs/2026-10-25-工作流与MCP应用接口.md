# 工作流与 MCP 应用接口

日期：2026-10-25。状态：实施中。关联 FW-R02/FW-R07/FW-R08/FW-R11/FW-R12/FW-R16/FW-R17。工作流编译编辑命令，MCP 和手动界面使用相同工程核心；真实 CLI 登录、推理与业务质量另验。

## 工作流与预设

- `GetWorkflowCatalog()` → `workflows.Definition[]`。
- `GetWorkflowPresets()` → `workflows.Preset[]`。
- `SaveWorkflowPreset({id?,name,workflowId,parameters,baseVersion?})` → Preset。
- `DeleteWorkflowPreset(id,baseVersion)` → void。
- `PreviewWorkflow({workflowId,selection,parameters})` → WorkflowPreview。
- `ApplyWorkflowPreview(id)` → Bootstrap。只接受后端保存的预览 ID，不把前端修改的命令作为已校验计划。

Definition/Input/Plan/Preset 的字段以 `internal/workflows/types.go` 为准。参数类型为 integer/number/boolean/string/select/asset/track，选项为 `{value,name}`。默认值和限制来自同一内置目录；保存参数预设不执行脚本或模型。

WorkflowPreview 内嵌 Plan，另含 projectRevision、createdAt、applied。Plan 包括 request、summary、effects、evidence、warnings、affectedClipIds、savedFrames。savedFrames 仅表示预计缩短的成片帧数，不是人工工作时长节省。词间 gap 来自已接受词，不冒充实际静音或语义删减。

应用先核对证据中的实际源文件、原工程实例、revision 和内容指纹；每个预览只提交一次，可整组撤销。源变更、锁轨、链接、绑定字幕与未选轨受统一核心约束。预览免费，不隐式生成媒体。

## MCP 生命周期

- `GetMCPStatus()` → MCPStatus。
- `StartMCP({projectId,allowEdits})` → MCPStatus。显式启动当前工程的 loopback 连接，默认不允许直接编辑。
- `StopMCP()` → MCPStatus。
- `GetMCPConnection()` → `{url,transport,httpHeaders}`，仅用户显式查看/复制；Authorization 不放普通状态、日志、工程或预设。

```typescript
type MCPStatus = {
  running: boolean;
  projectId?: string;
  projectRevision: number;
  allowEdits: boolean;
  scopeValid: boolean;
  reason?: string;
  address?: string;
  startedAt?: string;
  audit: Array<{id:string;tool:string;success:boolean;revision:number;createdAt:string}>;
};
```

连接只监听随机 loopback 端口，使用短期 bearer。工程关闭、切换或重新打开后，旧实例 scope 不再允许读取/编辑，用户可停止并重新连接。权限检查和实际提交在同一 Go 工程锁中；当前已授权的可撤销编辑不逐条要求用户批准。工具不取密钥、不执行任意本机命令、不读取未登记路径。

客户端以轻量 MCPStatus 的 revision 发现外部变化，只有需要时才拉 Bootstrap。有未提交 Inspector 草稿时暂缓刷新并保留草稿，旧 revision 失败不能用自动错误恢复把草稿清空；明确放弃/重读是用户动作。原有新建、打开、保存和关闭保护继续有效。

## 需要用户核对的请求

外部 MCP 工具只能准备模型生成/语音/导出请求。可能收费的操作不因模型传入 consent=true 直接执行；用户在客户端核对服务商、准确模型、数量、参考输入、上传和费用后确认。导出工具不接受文件路径，确认时由用户选择。

- `ListMCPRequests()` → MCPAction[]。
- `ApproveMCPRequest(id,{cloneConsent?,exportPath?,overwrite})` → MCPAction，仅客户端接口，不注册为 MCP 工具。
- `RejectMCPRequest(id)` → MCPAction。

MCPAction 为 `{id,projectId,projectRevision,kind,status,message,connectionId?,generation?,speech?,export?,jobId?,createdAt,updatedAt}`。kind 为 generation/speech/export；status 为 pending/submitting/started/failed/rejected；generation 使用 GenerationRequest，speech 使用既有 StartSpeechInput，export 仅 preset/fromFrame/toFrame/videoEncoder。

克隆声明由外部工具准备时清空，客户端确认必须由人重新提供主体及本人/授权声明。重复确认已 started 的同请求返回原任务，不再次扣费。停止连接会拒绝尚未确认请求；已经明确确认的独立任务仍在其原任务面板管理，不声称断开连接取消了远端计费。

## MCP 工具

读取包括工程摘要、分页素材/片段、转写目录与词窗口、工作流目录/预览、非秘密连接资料。允许编辑时另提供批量编辑、撤销/重做及应用工作流。写入要求版本/幂等，不能绕过素材导入、原始 ASR、锁轨或源区间规则。参数/输出和并发有界，旧协议及当前协议兼容以实际官方 client fixture 验证。

实际工具名与 schema 见 `internal/application/mcp.go`、`mcp_requests.go`、`workflows.go`；传输协议与固定 SDK 来源见 `internal/mcpserver/README.md`。没有把普通 CLI 快照计划模式说成已自动连接此 MCP；真实 CLI 工作流集成仍需对应会话/有效工具面验收。
