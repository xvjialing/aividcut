# macOS媒体SDK装配与重定位

2026-10-27，FW-R11/FW-R14/FW-R16，P0真实交付输入。上一轮相对入口已实现，但运行时仍有Homebrew绝对依赖。本轮在新隔离目录中使用显式Qt/MLT/FFmpeg SDK，完成macOS嵌套媒体后端.app、依赖复制/重定位、内部自签名和完整清单生成。Windows保留独立SDK/部署工具路线；跨编译清单工具不等于Windows媒体包完成。

优先使用已安装的Qt官方macdeployqt处理framework/插件部署，worker/FFmpeg/FFprobe与明确选择的MLT模块均进入额外可执行列表。必须显式提供离屏插件，qt.conf以macOS Contents为相对基点配置包内PlugIns。所有改写只在新拷贝中，原SDK不变；没有下载/安装/公开发布或默认选择商业许可。

官方工具退出0后仍遍历全部Mach-O，逐条把非系统依赖解析到包内确定文件，统一为相对loader路径，清理包外绝对rpath，内部symlink不越媒体目录。未能解析/缺文件/错架构/重写失败则装配失败，保留隔离目录，不静默保留开发机回落。普通导入闭包与动态加载另以真实运行采样核对，不扩张成任意服务或全部机器兼容性证明。

内部二进制变更完成后再本地ad-hoc签名、严格核验，然后生成runtime.json。新增跨平台Go清单生成命令，读取无payload规格，完整流式枚举后创建清单，调用同一Load校验；已有清单拒绝覆盖，失败只移除本次身份匹配的新文件。未批准许可/签名身份时releaseVerified保持false。

实际禁读开发SDK验证还要求完整MLT运行数据：清单v2增加data入口，包含loader.dict等文件，并由播放配置明确传MLT_DATA；v1保持原语义兼容，不能夹带v2数据目录。用户设置版本与SDK清单版本分别维护。

Wails构建可通过明确SDK输入选择随包拷贝，源与拷贝后都按目标平台/架构核对；没有输入则沿原构建行为。SDK先完整落入Resources/media再外层签名，不把未核对的目录复制到正式包。当前阶段仅私有验证，不自动变更默认发行依赖或编码器。

验收需要真实视频、文字、LUT、声音和淡化，移动后重新启动；静态依赖不再指向Homebrew，运行采样/禁止访问Homebrew的测试进程确认所测功能不会回落。测试本地素材服务需回环网络，不能把测试环境禁止listen误认为SDK不可用。许可、对应源码、DeveloperID/公证、干净机器、Windows实机和完整商业交付继续独立验收，模型账户按用户要求后置。
