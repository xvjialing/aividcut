# 属性输入首字符与捕获阶段

2026-10-27，FW-R01/FW-R03/FW-R12/FW-R17，P1/P2。补齐此前原生属性输入未确认项。本轮私有事件记录证明数字按键及 input 已到达实际控件；草稿捕获阶段同步设置提示状态，触发父层刷新，使子受控输入的 onChange 处理前恢复旧值。首字符丢失后继续输入会追加到旧值，错误值可被源边界校验拒绝。文本输入同样受影响。

修复只调整共享 useInspectorDrafts 提示状态的时机：原始输入仍同步记录到限定字段，写盘仍合并等待一秒；等待提示延后到完整原生事件结束后的任务中刷新。卸载取消提示定时器，已写完的版本不再被迟到等待提示覆盖；旧写入完成而新输入尚待保护时，提示不得宣称最新输入已保护。

不改变 NumberField 校验、工程命令、提交/失焦语义、IME 期间保护策略、字段范围或凭据边界。无效值和空数字仍可保留草稿，关闭保护不能被绕过。诊断事件接口和脚本只在 work 下的私有副本，不能进入正式客户端。

验收先通过原生 DOM/React 事件及捕获/冒泡边界回归复现，再核对修复后数字和文字首字符、首次及写盘后再输入、实际持久草稿一致、中文组合、卸载/迟到回执与无效关闭保护。最终生产构建副本应完成数值修剪、标题替换、保存重开和原生导出；浏览器和单测不能替代原生证明。账户及 Windows 实机按已有安排后置。
