# macOS原生媒体流程

日期：2026-10-26。关联FW-R01/03/06/09/10/14/15/17，P0/P1/P3。上一阶段已验证Wails3.0基本桥与保存，本轮补真实原生媒体链路，不使用实际模型账户。

使用独立数据目录、自建视频/图片/测试音调和内存假适配器保存的候选。经实际原生系统选择器打开工程，切换原片实时合成，验证定位/播放到末端、候选编排/撤销/保存重开及导出。至少核对导出视频/音轨的真实元信息、帧内容与声音存在，不把界面提示或任务成功当作成片证明。

本轮只操作已说明的测试数据，不读取密钥、登录或提交生成。发现故障按实际日志/源码定位并修复；前端/桥/渲染器相关变更才重跑对应检查。Mac锁屏时记录实际阻断，不自动解锁、不重复询问已答问题，继续其它独立检查。关闭窗口后不再getApp/getAXState以免自动重开，最终以进程和资料锁状态确认结束。

验收保留实际界面/过程、任务及成片证据、相关回归和限制，并同步路线图/需求矩阵/决策。视频/音色/自然素材质量、Windows实机和完整商业门槛不以本轮固定样本通过替代。

实际发现两项需修复的问题：工程更新时旧实时驱动吞掉新定位；macOS系统选择器将刚原子保存的自定义工程文件置灰。前者在共享实时驱动中保留暂停定位、继续阻止假播放，后者仅调整工程打开的系统类型兼容选项，最终格式/大小/结构仍由工程解析器验证。原生复查应覆盖同一进程中保存后再次打开，而非只验重启后打开。本轮没有新增字幕/LUT样本，这两项沿用此前独立媒体证据，不能扩大本轮通过范围。
