# 可复用编辑工作流

本包把参数与当前工程证据编译成真实 `editor.EditRequest`，不调用生成、ASR、TTS或本地CLI，不写工程或用户CLI配置。内置工作流和用户参数预设是两个层次：builtin方法说明只读，预设复用参数，实际应用总是重新读取工程并生成预览。

## 接口与应用边界

`Catalog(project)` 返回当前前置、参数和默认值；`Preview(project, Input)` 返回 `Plan`。计划包含工作流版本、原工程ID、基准修订、命令、说明、影响、来源证据、警告和受影响片段ID。它在独立核心副本上真正执行校验，锁轨、链接、源范围、字幕绑定与同轨冲突失败时没有可应用计划。

`Plan.Request` 只能由持有该预览的应用在版本与实际文件指纹再次核对后作为一次编辑应用。内置MCP工具为 `aividcut_list_workflows/aividcut_preview_workflow/aividcut_apply_workflow`，最后一个只在获得编辑授权的连接中提供。预览不会改调用方工程；统一核心负责原子失败及Undo/Redo。每个新预览有独立ID，同一预览的原请求可幂等重试。

`savedFrames` 始终是最终 `DurationFrames(before)-DurationFrames(after)`，可为负表示延长。口播summary另报所选完整源组删除的帧数，linked音画只计一次；未选配乐长尾存在时，总工程长度可能不变，计划会明确提示。

## 内置实际行为

- **talking-head**：以当前指纹与时长匹配、未陈旧的接受词为证据，只压缩可见词间的中心空隙。按词边缘、保留长度、句末标点及说话人切换保护，起点向上、终点向下量化到工程帧，不触碰首尾未知区间。过长空隙、与原始识别中未接受词重叠的间隔保留。词间无文字不证明静音或语义错误，必须试听候选。

  默认rippleScope=selection只闭合选中完整组；显式all_tracks将相同候选倒序复用核心全轨删除，作用于未选/隐藏/静音的所有轨道及后段。新speechRippleSummary报告完整统计，展示最多200明细/2000标识；其它被裁切媒体同样核对指纹，纯移动占位无需读源。受影响锁轨/字幕继承失败使整批拒绝，统一一次Undo/Redo，参数预设向后兼容。规格见[全轨口播粗剪](../../docs/specs/2026-10-27-口播粗剪全轨闭合.md)。
- **captions**：真正批量更新已有字幕的字号、颜色、背景、对齐和像素偏移，保留文字、时间与来源；核心保存人工样式覆盖。可明确全字幕范围，标题不改写，没有新转写或阅读断句承诺。
- **voiceover**：将已保存并导入的音频按元数据真实时长上轨，严格工程帧/源边界，尾部不足一帧保留在素材并提示。可启用同一音频已有真实接受词的绑定字幕；没有词时间就报前置，不按文案估时，不合成声音。
- **broll**：用已有视觉素材新增独立补充镜头，默认上层视频轨、默认静音，原音画不删改。明确源入点和帧区间，视频源不足时拒绝；不生成或捏造文件。

口播首轮最多32个时间不重叠的完整源组、128处候选；linked成员须有相同工程起止与速度。新保留段先通过 `duplicate_clip` 明确父源，再修剪原ID，继承跨gap的字幕文本/样式覆盖。只闭合所选完整源组，未选轨不移位；若闭合后与未选片段冲突，整个预览拒绝。复杂多机位、独立速度链接、语义删句与全工程波纹后续单列，不自动猜主轨。

已启用的字幕规则始终由工程核心维护。配音工作流不会偷偷关闭旧规则，也不会通过改字幕目标影响未选源复用；静音B-roll遇到自身持续对白字幕规则时要求独立补充素材。大量同时字幕的阅读布局、样本级音频尾对齐及整机长素材性能不属于本次小fixture验收。

## 内置说明与预设

`BuiltinSkill(id)` 从包内 `builtin/<id>/SKILL.md` 读取中文方法说明，包含真实参数和工具；登记的方法通过embed进入应用，不安装到Codex/Claude用户配置。用户预设用 `NewPresetStore`，提供List/Get/Save/Delete，ID稳定、版本乐观校验、原子JSON保存。builtin定义不能经预设接口覆盖。Store的单路径只允许一个owner，应用负责进程锁。

## 批量声音淡化（2026-10-27）

audio-fades明确scope=selection/project，空选区不能自动当整个工程；只处理范围内匹配的声音，不展开linked组。默认只音频、当前可听声音、保留已有曲线；设置/清除、含视频原声、静音内容、覆盖和短片段策略均明确。设置用editor.NewAudioFade/FittedAudioFade，渲染与原音量/静音/源窗不重写；离线只改元数据。一次最多1000条实际变更/200明细，锁轨或超过上限整批拒绝。

AudioFadeSummary统计完整范围，实际时长在明细；改选区的迟到预览不接纳，同ID新工程实例重挂界面，应用仍绑定核心实例/修订。参数预设不保存执行范围，重用时重新明确。规格见[批量声音工作流](../../docs/specs/2026-10-27-批量声音淡化工作流.md)。

预设可以保留未选择的素材/轨道参数以便复用，Preview才校验当前工程实际素材、轨道、指纹和词时间；跨工程须重新选择相应ID。没有把一组参数保存成功当作对应模型、素材、账号或生成质量已验证。

## 验证范围

算法fixture实际应用并Undo/Redo，覆盖29.97fps词间内缩、句末/说话人/未接受原始词保护、完整linked组和未选配乐、跨gap字幕人工覆盖、相关锁轨、并行源拒绝、实际字幕样式、真实时长编排、真实接受词字幕、上层Muted B-roll、计划输入隔离和缺前置拒绝。语音/素材只使用工程已有证据，不发生收费调用。

```sh
go test -race ./internal/workflows ./internal/editor
go vet ./internal/workflows ./internal/editor
```

2026-10-26：builtin/source-frames/SKILL.md为独立源画面输入的方法补充，由明确开启画面许可的CLI执行注入；它不作为第五个确定性编辑工作流，也不自动上传整个素材库或改写工程。其读图/引用要求与MCP工具一起验证，真实模型语义质量后置。

## 视频补充镜头的原处理配方（2026-10-26）

broll新增视频在源范围检查后统一CaptureSourcePhase，保留首次源窗及AudioRange；参数契约不变，生成候选直接上轨也复用同一编译器。默认新上视频层/静音与显式轨保护不变；静音持续字幕源仍拒绝，正常源字幕由核心按新实例派生。真实PCM/RGBA与独立手工基线相同的记录见[候选上轨验收](../../docs/implementation/2026-10-26-生成候选直接上轨验收.md)。
