# 本机媒体工具设置

保存五类本机路径或随包自动模式，不安装工具、不读取执行`.env`，不扫描其它应用。`settings.json`现保存版本2、读取版本1/2，32KiB上限、严格字段、手动绝对路径；文件置于用户应用数据的`media-tools`目录，以系统单写锁和临时文件同步/原子替换保存，不写工程包。无文件默认`useBundled=true`，自动模式只保存模式和空路径；旧v1均保持手动语义，空FFmpeg/FFprobe交给PATH、空worker不启用原生预览。损坏文件保留并沿原环境/PATH回退，不借异常文件激活随包引擎。

应用层`media_settings.go`负责明确候选检测、20秒总预算、工具/目录身份与原始配置摘要证明、16份/10分钟上限，以及只凭检测ID保存。候选输入变化后重检；保存不替换当前工具，下一次启动生效。身份/mtime不是签名或许可认证；真正使用时仍有媒体任务与原生图校验。

自动模式由`mediaruntime`从产品相邻位置验证清单，环境变量优先，相关原生环境覆盖不混用随包插件。清单存在但损坏时停止自动PATH回落，当前来源明确；候选检测不受环境覆盖，保存再次核对随包指纹/内容。GUI保存失败会清除旧检测状态并保留输入，要求重检；手动草稿切换模式往返可保留。[随包规格](../../docs/specs/2026-10-27-随包媒体运行时发现与校验.md)。

损坏普通JSON保留并回退环境/PATH，可显式重新检测保存。无法确认的特殊文件、符号链接、超大或不可读文件需先保留资料并手工修复，不能借GUI覆盖未知资料。私有目录权限是创建时请求值，不声称修复已有目录权限或具备完整断电持久性。

规格见[媒体工具持久设置](../../docs/specs/2026-10-27-媒体工具持久设置.md)，实际范围见[验收](../../docs/implementation/2026-10-27-媒体工具持久设置验收.md)。
