# 工程字体资源

本模块只解析和校验用户选择的静态TTF/OTF，不安装系统字体。`Read`校验32MiB以内的普通文件、SFNT目录和名称表，拒绝集合、可变、彩色及CFF2字体，保留文件内版权/许可声明并计算SHA256。解析采用固定的Go官方x/image v0.47.0。

`Resolve`按文字/字幕实际引用读取，最多32份/128MiB，核对完整内容与登记元信息，逐字形查询用于拒绝所选字体缺字。它不以字体名称替代文件证明，不证明所有语言的复杂排版。Go核心只保存font Asset和TextStyle.fontAssetId，字体读取在应用/媒体层完成。

会话素材服务只有已引用、校验过的字体才发放带令牌的字节读取；响应重新校验内容后才允许CORS，普通媒体和未授权请求不增加此权限。客户端核对同一SHA后加载FontFace，按引用复用并释放。原生进程加载并核对同一文件，再按实际Qt字体表/字形运行核对与测量；测量和qtext/原生导出共用同一选择。FFmpeg路径保留独立字体文件，不保证不同排版引擎逐像素相同。

工程收集沿通用Asset流程携带字体，重定位要求同内容。文件内声明仅作追溯，不能代替字体授权；独立附带许可文件的自动识别/收集尚未实现。说明与证据见[工程字体验收](../../docs/implementation/2026-10-27-工程字体资源验收.md)。
