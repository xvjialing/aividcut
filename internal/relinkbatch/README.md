# 明确目录映射的素材修复

`Inspect`读取登记素材当前是否存在及建议旧目录；`Prepare`将旧根下的离线路径映射到明确的新根，逐文件SHA256核对，不递归搜索。视频、音频、图像、LUT与字体不复制业务适配器，已知同内容时只修路径，原始媒体不改写。

每批最多256个目录内离线素材、64GiB实际读取预算。只取非空普通文件，规范路径必须仍在新根内，`os.Root`限制实际打开；同目标文件共享一次摘要。没有原始SHA256、目标缺失、内容不同或无法稳定读取分别列状态，目录外和仍存在的原位置不自动更新。

应用层将不可变计划绑定ProjectScope和10分钟有效期，单个读取/应用上下文3分钟，可取消。提交前`Verify`重新读取摘要，`CheckFiles`再核对根与文件身份；`Commands`从权威工程克隆素材，仅写路径/缺失状态/临时URL。统一editor事务保证锁轨、字幕、精确音频元数据和一次Undo，任何后端失败整批不提交。文件系统外部写入不由本程序锁定，核对不是永久文件保护。

最多保留32个待处理计划和512个短期请求身份。取消/已应用计划释放文件证明，取消凭据仅阻止同ID晚到请求复活，不占待处理计划额度；已验证连续40次提前取消后仍可正常核对。

新导入LUT现保留SHA256；旧无指纹素材继续走现有单文件核对及锁轨规则。该模块不授予MCP新的目录读取/素材写入能力，计划不跨重启持久化。[规格](../../docs/specs/2026-10-27-目录迁移批量素材修复.md)。
