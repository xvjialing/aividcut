# 已注册候选的镜头替换

本包只把当前工程里已注册的本地视觉素材编译为可审阅编辑，不生成、下载或修改媒体文件，也不调用语音/收费服务。应用应先将生成结果保存并Probe，再把经过实际文件指纹校验的候选传给本包；普通前端编辑桥不应开放隐藏的原声承载字段或任意源转写对象。

## 接口

`Preview(project, Input) (Plan, error)` 是纯预览：在 `editor.NewEngine` 的独立副本上真正校验全部请求，返回稳定预览ID、原工程ID、原修订、编辑请求、影响说明、素材指纹/源范围证据、警告和受影响片段ID。应用保存该预览并再次核对工程/实际文件后，使用原 `Request` 原子应用。同一预览的幂等键就是预览ID，重复应用不会新增原声；Undo/Redo恢复整个原画面、原声、字幕与新轨道。

`Input`：

- `clipId/assetId/sourceInUs`：明确当前视觉片段、已注册video/image候选和微秒入点，候选默认入点0。
- `audioMode`：`keep_original`（默认）、`use_candidate`、`mute`。
- `lutMode`：`keep`（默认）或`clear`。
- `speedMode`：`preserve`（默认）或`normal`。
- `transform?`：省略时保留原变换；后端可显式覆盖，首轮界面可不展示。
- `audioTrackId?`：需要分离原声时的音频目标轨，省略新建轨；目标重叠或锁定则拒绝。

替换始终保持视觉片段ID、轨道、时间线起点与长度，不碰未关联片段。candidate源不足时拒绝，不自动补帧、循环、缩短或偷偷调速。保留视频速度时按原有有理数速度检查真实源余量；normal明确1x。图片没有源播放速度，固定1x；图片转视频也明确1x并说明。原声独立承载始终保留旧讲话的速度和源入点。

## 声音和字幕来源

keep_original保持原来的可听状态；已有独立linked音频不复制。原视频本身可听的音轨要成为真实audio轨片段，直接引用原 `HasAudio=true` 的video Asset已有音轨，不创建伪audio文件或伪造指纹。已有同源/同映射linked audio可直接复用。若原视频与已有linked声音原本都参与混音，本次只替代旧视频的那份声音贡献，已有linked片段未复制，影响中会说明。

use_candidate只允许有真实音频流的视频、正片段音量和未静音的视觉轨；相关linked原声会按显式请求静音。mute关闭目标和关联原声，不静音未选背景音乐。没有声音的图片/视频不能被报告为候选声成功。

原讲话绑定字幕不会跟到新画面。新核心 `replace_visual` 在一个领域步骤中替换视觉、创建/核对同源audio carrier，并迁移 `CaptionSource.SourceClipID` 和 `CaptionExclusions.SourceClipID`。原Transcript ID、原始词、接受修订、稳定字幕ID、人工文本/样式/布局都保留。解绑的静态字幕不变，手动删除/解绑的词不会重新生成。

即使选择候选声或静音，仍有旧讲话字幕时也保留真实旧音轨承载，但它明确Muted；不会声称旧讲话在播放，也不声称旧字幕已对齐候选新声音。原声应在可编辑的真实audio轨；原字幕轨、源轨或需要变化的linked轨锁定时整批拒绝。

## 首轮明确限制

- 候选自身已有持续源字幕规则时拒绝，避免全局派生把新画面错误当旧讲话或产生新对白；应先明确独立的字幕来源。
- 原链接组含其它视觉/文字片段，或迁移原字幕时同时存在另一套活动讲话转写时拒绝，不猜复杂多机位/多来源字幕映射。
- 保留字幕需要原video确有音频流。不同文件的已链接音频不能被冒充为相同指纹的ASR源；不能安全复用时保留同原视频的真实承载，或明确拒绝复杂来源。
- 元数据规划不证明视频中每一秒都有音频。承载与原视频使用完全相同源/时间/速度/音量，保持原可听覆盖，不给缺失音轨尾部补声音。实际文件与音轨由应用/媒体层核对。
- 保留Transform/LUT不等于新画面已完成艺术构图和色彩匹配；首轮不做自动构图或调色，也不把元数据fixture当作整机播放/导出验收。

## 验证

语义fixture实际应用并Undo/Redo，覆盖跨图片/视频、原/候选/静音、原速度与1x、LUT保留/清除、同源音轨引用、原linked音频不重复、旧字幕ID/人工覆盖/排除迁移、锁轨、目标重叠、余量不足、无声候选、隐藏carrier字段拒绝、幂等与调用方隔离。

```sh
go test -race ./internal/replacements ./internal/editor
go vet ./internal/replacements ./internal/editor
```

测试不调用模型或真实账户。真实媒体渲染与应用预览/文件指纹复核需在应用和媒体集成层另外验证。
