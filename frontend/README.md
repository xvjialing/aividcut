# AIVidCut 前端

React + TypeScript + Vite 的首轮剪辑工作区。运行时使用 Wails v3 `@wailsio/runtime` 的 `Call.ByName` 与 `Events.On`，集中于 `lib/desktop.ts` 和类型化 bridge。运行时按需加载，普通开发浏览器不会触发其初始化请求；开发环境经 `/api/{method}` 联调同一 Go 服务。正式版本缺少 Wails 桥时不会静默创建假工程或使用开发 HTTP。

## 开发

使用 `package.json` 固定的 pnpm 12.15.0；Node 范围为 `^22.22.2 || ^24.15.0 || >=26.0.0`，本机验证版本为 24.16.0。已有 Corepack 时可用 `corepack enable pnpm` 启用对应命令；本工程不会修改全局包管理器配置。

先在工程根目录启动 Go 开发服务（默认 `127.0.0.1:43110`），再在本目录执行 `pnpm install --frozen-lockfile`、`pnpm run dev`。自定义服务地址使用 `AIVIDCUT_BACKEND=http://127.0.0.1:端口 pnpm run dev`。构建 `pnpm run build` 产生 `dist/` 供 Wails 嵌入；工程根目录的 `make setup/dev/build/run` 入口不变。

所有原有依赖版本保留，唯一活动锁文件为 `pnpm-lock.yaml`。安装采用 pnpm 隔离链接结构，通过同磁盘的用户共享内容 store 复用包；不启用实验性全局虚拟 store。普通终端可用 `pnpm store path` 查看实际位置，受限沙箱可能回退到项目内 store；若目标是跨项目节省空间，应使用可访问用户共享 store 的终端安装。`du` 不足以精确衡量 APFS clone 的整盘物理节省。根目录 DESIGN.md 记录当前实际 token 与用途，UX-CONTRACT.md 记录交互 owner 和业务来源。

## 当前可用

Timeline以lib/timeline-index.ts的只读区间/吸附索引查询可见行和时间段；标题与内容共享纵向滚动、66px行高、两行预留，焦点/捕获暂时固定。远选择可定位、轨道键盘可跨未挂载行，滚动补偿不创建额外编辑历史。完整规模与平台限制见根文档的前端可见区验收。

素材库、源素材/活动片段工作区预览、播放定位、四类轨道、片段移动/修剪/分割/删除、属性和文字编辑、LUT 选择、撤销/重做、新建/打开/保存、导入与真实导出任务。所有写入通过 Go 命令，锁轨/边界/版本由核心验证。开发版对话框支持输入本机路径以便联调。

素材面板的“字幕”页支持静态 SRT 导入、导出全部字幕轨、文字筛选、点击定位与手工新增字幕。字幕按工程时间放置，视频剪辑后需核对字幕时序；该入口不提供 ASR。桌面使用原生 SRT 选择器，开发联调使用应用内路径框，成功显示实际导出路径。

窗口关闭在监听注册后通过 FrontendReady 握手；先 blur/等待属性提交，再读取最新工程 dirty。输入非法、提交或核对失败保留窗口，避免依据旧干净状态关闭。

新建/打开也复用同一草稿稳定与最新状态检查。属性数字为必填，DOM validity 与提交检查一致，jsdom 直接渲染 Inspector 验证空值、失焦草稿和真实 blur 顺序；该检查不等于实际 Wails 运行证明。

缺失素材卡、素材详情与片段源区提供“重新定位素材”。桌面使用原生选择器，开发环境用路径 Modal；只调用 RelinkAsset/RelinkAssetPath，不通过重新导入重建素材。后端核对同一文件，成功保留片段 ID、源区间与编排。已有原生桥缺少新增方法时会明确报未就绪，不静默转到另一个 HTTP 工程。

右侧“生成”页已接入模型连接、能力目录对应表单、计费前核对与独立生成任务。配置密钥默认遮盖，保存成功或取消清空；配置成功不表示账号权限已验证。只有明确点击计费确认才提交生成，测试使用注入 mock API 并禁止真实网络。

任务区支持停止本地等待、恢复已有查询、核对不可恢复 unknown，以及显式选择候选或全组加入原工程素材库。部分导入不禁用剩余候选；不同工程不能误导入。停止等待不代表远端取消，不显示虚构百分比或费用；Seedance 保持未验证禁用。生成结果不会自动替换镜头；每个已保存视觉候选可通过“替换当前镜头”先核对源区间、声音、LUT和速度，再明确应用并整组撤销。

AI 助手支持本地 Codex CLI/Claude Code 检测、独立作用域登录说明、可用工作流、明确额度确认后生成候选计划、结构化命令摘要与显式应用。未安装、未登录或隔离未通过均不允许规划；旧工程、旧版本或未经核心校验的计划不能应用。登录信息仅供复制，不自动执行；剪辑要求通过结构化桥数据传递。应用走统一工程通道和撤销历史，Undo 不会让同 ID 自动再次执行。

助手以“规划、执行、工作流、工具连接”单行标签切换。执行模式独立检查第一方MCP隔离，明确CLI额度与整个工程工具权限（选区仅上下文），可切只读；运行可取消，已提交编辑保留并逐批撤销，模型收费仍人工核对。

助手另有工作流和 MCP 视图。工作流按目录动态生成参数，预设显式载入/保存/删除并携带版本，预览展示影响与证据，再明确应用并保留撤销。MCP 默认只读且需手动启动，可单独允许可撤销编辑；连接配置只在明确查看/复制时加载，不自动改外部 CLI。外部生成/语音/导出只准备请求，收费与导出需在客户端再次核对。

MCP 运行时通过轻量 revision 检测外部修改。有属性草稿或拖动手势时保留当前编辑上下文并暂停同步，失败恢复不能擦掉草稿；明确重读后继续，避免旧片段字段覆盖外部结果。原新建/打开/保存/关闭保护保留。

语音页支持源素材转写、指定音色配音、音色显式分页查询与自定义音色、独立任务/详情及结果应用。上传与可能计费需单次明确确认，克隆额外要求本人或授权声明且结果仍未验证。原始词缺失时间不补零；完整普通词可接受到工程并可选派生绑定字幕。已接受源词可按稳定 ID/源微秒纠错，字幕可明确解绑。真实配音使用本地签名 URL 试听，按实测时长导入素材库或音频轨。未知提交不自动重交，本地恢复不重做收费请求。

配音可明确获取一次生成的真实时间，原文和朗读文本分别核对，缺时间仍可单独导入音频；字幕来源不自动互换。带时音频可一并添加字幕，已有素材的全部上轨片段都会参与且不重复添加配音。已接受的来源固定，改排版/目标轨需预览后应用，人工修改受保护并可整组撤销。来源面板提供逐词/阅读分句，用户单位为秒、字、行；显式新建轨与返回轨道状态一致。字幕时间详情与排版面板按需加载。

工作区预览不宣称专业原生多轨实时合成已达标；LUT、字体与换行通过后端合成检查核对。缺少媒体能力或前置数据的功能明确禁用，不显示假完成状态。Windows/macOS实机、真实图片/视频/语音/CLI账号与质量、系统凭据存储、大工程完整资源、完整无障碍验证仍需阶段实测。

## 检查

- `pnpm run typecheck`
- `pnpm test`
- `pnpm run format:check`
- `pnpm run build`

素材派生图使用`SourceThumbnail`与`AssetSourceBrowser`，通过类型化thumbnailAPI访问后端；可见性、共享在途队列、取消/失败/重试、图片解码状态和sourceEpoch共同保护当前素材。视频取样与180ms稳定滑条为只读源浏览，不定位中央播放器或编辑时间线。当前210项前端测试通过，真实Go操作及小桌面证据见[素材浏览验收](../docs/implementation/2026-10-25-素材缩略图与源画面浏览验收.md)，新界面双端原生仍待验收。

`ExportSettings`和`export-options`复用共享表单/Modal，提供自动/原生/FFmpeg、画幅/编码、整数半开区间及显式替换。错误保留草稿并聚焦对应字段，导出只提交快照任务；MCP待核对条目展示固定后的实际方式。31文件216项测试、真实导出/故障恢复及实时Canvas比对通过，见[导出验收](../docs/implementation/2026-10-25-原生合成与一致导出验收.md)。原生系统Select展开视觉仍需双端实测。

实时模式增加full/half/quarter合成精度，通过类型化startPlayback参数传递；精度属于预览会话，新工程默认全精度，切换先核对草稿并保持当前帧暂停重准备。共享Select保留input/select基础样式，219项前端测试及真实900px/小画幅恢复通过。固定资源与不变PCM、原画幅导出边界见[精度验收](../docs/implementation/2026-10-25-可调预览合成精度验收.md)，系统菜单双端原生另验。

## 当前画面参考（2026-10-26）

Preview通过CaptureIntent把源位置或时间线帧交给生成页。FrameCapturePanel按需加载，位于generation-form滚动区且在生成form之外；保存经共享工程队列调用独立frameCaptureAPI。图片是普通素材，用户再按模型能力明确选择参考，生成确认/提交保持独立。未知结果重试保留原输入，sourceEpoch隔离晚响应，Undo后的旧请求不重新导入。真实媒体与浏览器证据见[验收](../docs/implementation/2026-10-26-当前画面参考素材验收.md)。

## 生成候选对比（2026-10-26）

GenerationJobs按当前任务读模型解析最多两个比较身份，比较选择与导入复选框独立。CandidateComparisonDialog按需加载，SavedCandidateMedia为列表/对比共用成品读取和暂停释放组件；对比默认静音并避免双视频同时播放/发声。导入与转入替换沿现有回调，sourceEpoch重挂清空旧作用域，Modal可选onCloseAutoFocus保证返回焦点。新增8项DOM回归及真实Go/媒体记录见[验收](../docs/implementation/2026-10-26-生成候选并排对比验收.md)。

## 生成参数复用（2026-10-26）

GenerationReuseDialog按需加载，通过独立generationReuseAPI读取真实成功配方，核对后预填原创作表单。父配方与参考证明属于草稿；未导入PNG/JPEG候选沿原importResults共享通道加入素材再加载。稀疏参数保留默认语义，能力effect消费跨连接预填；生成内容签名排除父配方但请求ID签名保留来源。最终SubmitGeneration附可选工程Context，版本/实例变化拒绝。新增9项前端回归与真实本地浏览器证据见[验收](../docs/implementation/2026-10-26-生成参数复用与图片继续修改验收.md)。

## 生成候选上轨（2026-10-26）

GenerationPlacementDialog按需加载，输入位置/源窗/目标轨/声音，generationPlacementAPI只准备与应用服务端预览。I/O由App与Timeline共享，Timeline仍支持旧未受控调用；sourceEpoch隔离旧标记。任务卡/对比可转入添加，处理窗沿SavedCandidateMedia暂停列表媒体。应用走共享工程通道，成功选择实际新片段，参数失效/失败与返回焦点有回归。详见[验收](../docs/implementation/2026-10-26-生成候选直接上轨验收.md)。
